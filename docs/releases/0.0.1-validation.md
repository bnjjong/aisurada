## 아직 포함하지 않은 검증

- 개발 도구가 전혀 없는 별도 Mac에서 Finder로 수행하는 전체 설치·편집 시나리오
- macOS 13을 포함한 지원 운영체제별 실제 실행
- 기존 설치본·기존 워크스페이스의 업데이트 호환성
- Gatekeeper의 Developer ID·공증 승인 (ad-hoc 시험판이므로 제공하지 않음)
- Claude 실제 계정 연결 및 미설치 Git의 기능별 안내 전체

번들 자동 검사는 LaunchAgent를 등록하지 않습니다. 별도 로컬 검사에서는 임시 HOME을 지정하는 래퍼로 실제 launchd 자동 시작을 확인했고, 생성한 등록은 정리했습니다. 이는 개발 도구 없는 별도 Mac과 앱 화면의 전체 수동 검증을 대신하지 않습니다.

# aisurada 0.0.4 — 글 유실 방지와 화면 사용성 안정화 배포

Apple Silicon Mac용 `0.0.4` 배포입니다. **설치 파일은 Assets의 `aisurada_0.0.4_aarch64.dmg`입니다.**

0.0.3 이후 UI 점검에서 나온 결함을 모아 고친 배포입니다. 쓰던 글이 사라지는 문제를 가장 먼저 다뤘습니다.

## 주요 변경 사항

- **쓰던 글이 사라지던 곳을 막았습니다.**
  - 새 문서·아젠다·프로젝트 창, 코멘트 입력창, 문답 이어 묻기 카드에서 Esc나 바깥 클릭으로 작성 중인 글이 날아가지 않습니다.
  - 질문을 쓰다가 Esc를 눌러도 내용이 남고, 실행을 취소하면 입력했던 질문과 이미지가 다시 채워집니다.
  - 아젠다 사실층 초안은 화면을 옮겨도 남습니다. 읽기에 실패하면 무한 로딩 대신 「다시 읽기」가 나옵니다.
- **종료와 창 닫기를 고쳤습니다.**
  - 앱을 끌 때 열려 있는 노트 창을 각자의 저장 절차로 닫습니다. 노트 창을 닫기 전에 「종료 중」 표시를 먼저 켜서, 끄기 직전에 열려 있던 노트 창이 다음 실행에 되살릴 목록에서 지워지지 않게 했습니다. 종료를 취소하면 닫힌 창 목록이 유지됩니다.
  - 노트 창을 닫을 때 뜨는 「그래도 닫기」 단추가 모든 테마에서 읽히도록 빨간 바탕에 흰 글자로 바꿨습니다.
- **파일 끌어 놓기와 질문 멈추기를 더했습니다.** 편집기 본문에 파일을 끌어 놓으면 첨부 폴더로 복사하고 이미지나 링크로 넣습니다. AI 질문은 세션 화면과 대기줄의 멈추기 단추로 중단할 수 있고, 중단해도 앞서 나온 출력은 남습니다.
- **외부 변경 충돌 화면을 안전하게 했습니다.** 「내 편집 버리고 외부 파일 불러오기」는 확인 창에서 답을 받은 뒤에만 실행됩니다. 앱 안의 확인 창이 비동기라 답을 기다리지 않고 진행되던 문제를 고쳤습니다.
- **편집기 사용성을 개선했습니다.** 밑줄 서식 저장, 표 칸 하나를 복사했을 때 표 전체로 오인되던 문제, 한글 조합 중 슬래시·노트 메뉴가 닫히던 문제, 슬래시 메뉴 위쪽 열림, 깨진 이미지 대체 표시를 고쳤습니다.
- **캘린더 일 보기 카드가 겹치지 않습니다.** 시간축을 넓히고 카드 높이를 고정했으며, 겹치는 시간대끼리만 칸을 나눕니다. 60분 간격 일정 사이에는 틈이 생깁니다.
- **테마와 창 크기 대응을 정리했습니다.** 메인 창 최소 폭은 900px이고, 1100px 이하에서는 레일이 덮는 형태로 바뀝니다. 스킨별 선택·호버 색, 유리 스킨 헤더, 어두운 테마 글자 대비, 「애니메이션 줄이기」 설정을 손봤습니다.
- **Claude·Gemini 세션 화면을 다듬었습니다.** 세션 탭 제목 축약, 문답 카드 위치 보정, 자동 스크롤, 질문 즉시 전송 표시와 중복 전송 방지, Gemini 전송 시 안내를 정리했습니다. Claude가 오류 코드 1로 끝난 것을 로그인 오류로 잘못 안내하던 문구도 바로잡았습니다.
- **아젠다·캘린더·폼 상호작용을 정리했습니다.** 아젠다 항목의 한 번 클릭과 여러 번 클릭을 나누고, 캘린더에서 오늘 날짜를 강조하며, 모달 포커스 이동과 주요 단추의 접근성 이름을 보강했습니다.
- **엔진 안정성을 높였습니다.**
  - 정비 커밋은 파일 쓰기 중이면 건너뛰고 5초 뒤 다시 시도합니다.
  - YAML 접는 블록(`>`)에서 줄바꿈이 늘어나거나 끝 빈 줄이 사라지던 문제를 고쳤습니다.
  - 휴지통이 1MB를 넘어 자동으로 영구 삭제된 항목은 화면에 알립니다.
  - 쓰이지 않던 세션 전사 캐시 코드를 정리했습니다.

## 알려진 문제

- 충돌 화면에서 「내 편집 버리고 외부 파일 불러오기」를 누르면 뜨는 확인 창의 제목이 「첨부 열기」, 확인 단추가 「열기」로 나옵니다. 취소하면 편집이 그대로 남고, 확인하면 버립니다. 다음 배포에서 문구를 고칩니다.

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 21 런타임 동봉: Java 별도 설치 불필요
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.0.4_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다.
3. Applications에서 앱을 실행합니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

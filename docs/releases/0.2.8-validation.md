## 주요 수정 사항

- **C4 아키텍처 다이어그램 다시 불러오기 개선 (PR #186)**
  - 기존 시계(`history`) 아이콘을 **순환 회전 화살표(`refresh`)**로 교체하여 버전 이력(Time Travel)으로 오인되는 문제를 해소.
  - 마우스 호버 시 `다시 불러오기` 툴팁 제공.
  - 클릭 시 즉각적인 360° 회전 애니메이션(`.c4-refresh-spin`) 피드백을 제공하여 동작 여부를 시각적으로 명확히 전달.
- **좌측 네비게이션 액티비티 바 아이콘 시스템 전면 일관화 (PR #186)**
  - 하단 유틸리티: 폰트 렌더링에 의존하던 유니코드 텍스트 기호(`◐`, `?`)를 제거하고, 1.5px stroke 규격의 **정밀 SVG `theme`(반달)**과 **`help`(원형 배지 물음표)**로 100% 교체.
  - 설정(`settings`): 찌그러짐 없이 완벽한 대칭형의 **표준 8-Teeth 기계식 기어**로 전면 개편하고 크기를 `18px`로 통일.
  - 상단 탭: `note`(노트 본문 라인 추가), `globe`(단정한 3선 구형 심볼), `bot`(지능형 에이전트 마크)의 선과 디테일을 정돈하여 전체 화면의 시각적 균형 확보.
- **C4 다이어그램 시간 여행(Time Travel) 이력 지원 (PR #187)**
  - C4 아키텍처 모델의 Git 커밋 기반 변경 이력을 탐색하고 과거 시점의 다이어그램을 확인할 수 있는 이력 기능 추가.
- **볼트별 Git 설정 지원 (PR #188)**
  - 각 vault 워크스페이스별로 독립적인 Git 커밋 및 동기화 옵션을 설정할 수 있도록 확장.

## 로컬 릴리즈 빌드 및 번들 검증

`AISURADA_RELEASE_TAG=v0.2.8 pnpm --dir native-host release:build` 명령으로 검증 및 패키징을 수행합니다. 번들 빌드와 번들 검증 10항목을 통과합니다.

- **번들 검증 10항목:**
  1. 앱에 `ais-cli`·라이선스·사용자 안내서가 든다
  2. Java 런타임과 JAR이 없다
  3. 번들 버전이 0.2.8이다
  4. ARM64 앱과 `ais-cli`와 안쪽 코드의 서명 검증
  5. 번들 `ais-cli`가 한글·공백 경로에 작업 공간을 만든다
  6. PATH에 아무것도 없이 번들 CLI가 노트를 만들고 따로 뜬 프로세스가 읽는다
  7. Claude MCP 등록이 번들 `ais-cli`를 가리킨다
  8. 번들 `ais-cli`가 표준 입출력 MCP를 서비스한다(`initialize`, `tools/list`, `tools/call`)
  9. DMG를 꺼낸 뒤에도 복사한 앱의 엔진 검사가 통한다
  10. 복사한 DMG 앱이 격리 HOME에서 계속 떠 있다

- **크기:**
  - DMG: 17,316,585 바이트 (약 16.51 MiB)
  - 앱 번들: 36,936 KiB
  - 동봉 CLI (`ais-cli`): 5,662 KiB

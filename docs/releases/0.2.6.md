# aisurada 0.2.6 — 네이티브 C4 아키텍처 모델 및 매니저·타입 안정화 패치

Apple Silicon Mac용 `0.2.6` 패치 배포입니다. **설치 파일은 Assets의 `aisurada_0.2.6_aarch64.dmg`입니다.**

0.2.5 이후 **네이티브 C4 아키텍처 모델 지원**, **매니저 인테이크 및 제보 대화 연동 강화**, **리뷰 후속 조치(R1~R5) 2차 안정화 및 엄격한 IPC 타입 검사 강제**를 포함하는 패치 업데이트입니다.

## 주요 변경 사항

- **네이티브 C4 아키텍처 모델 도입 (PR #165, #168)**:
  - 엔진 C4 모델 명령 및 아키텍처 편집 화면 지원 (`TSK-24`).
  - Rust 네이티브 엔진 기반의 아키텍처 구조 관리 및 직관적인 다이어그램 모델 편집.
  - 매니저 태스크 상태 변경을 제보 대화로 알리는 실시간 알림 연동 (`TSK-20`).

- **매니저 인테이크 및 질문 연동 강화 (PR #166, #167)**:
  - 저장된 인테이크 질문 전달 및 알림 통합 (`TSK-20`).
  - 모듈 규칙을 준수하는 노트 임포트 구조 정비.

- **입력 유효성 검증 및 오류 방어 (PR #169)**:
  - 빈 문자열로 끝나는 질문 답변 제출 차단 및 유효성 오류 안내 (`TSK-4`).

- **리뷰 지적 2차 후속 조치 및 엔진·호스트 타입 완전 안정화 (PR #170 및 릴리즈 반영)**:
  - `task/format.rs`의 `refs()`에서 `java_trim`을 적용하여 `" github"` 등 앞뒤 공백이 포함된 ref 인자를 정상 수락하도록 회귀 수정.
  - 삭제된 `archyl_*` 명령 6개를 `HostCommandMap`에서 완전 제거하여 불일치 해소.
  - `TypedHostCall`에 판별 유니온 튜플을 적용하여 `<T>` 결과 타입을 직접 명시하더라도 명령 이름에 맞는 인자 검사가 유지되도록 타입 검사 구멍 차단.
  - `notifications_mark_read`의 `ids: string[] | null` Rust 시그니처 1:1 일치.
  - `AIS-412`와 `AIS-409` 및 태스크 상태 충돌 분기 단위 시험 보강.
  - 골든 bless 도구 전체 로그 출력 개선.
  - 개발자 가이드 시험 수치 최신화 (엔진 358건, Node 702건).

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 불필요 (100% Rust 네이티브 엔진)
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.2.6_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다. 이전 버전이 있으면 덮어씁니다.
3. Applications에서 앱을 실행합니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

# aisurada 0.0.9 — IntelliJ 스타일 도구 막대 개편과 아수라다 컴패니언 헤더

Apple Silicon Mac용 `0.0.9` 배포입니다. **설치 파일은 Assets의 `aisurada_0.0.9_aarch64.dmg`입니다.**

0.0.8 이후 사이드바 레이아웃을 IntelliJ New UI 스타일 도구 막대(Activity Bar) 구조로 전면 개편하고, 아수라다 브랜드 마크의 사용 면적을 복원한 컴패니언 헤더 카드 구축 및 알림 벨 재배치, 글로벌 리소스 관리 연동을 추가했습니다.

## 주요 변경 사항

- **IntelliJ New UI 스타일 도구 막대(Activity Bar) 도입 및 사이드바 개편**
  - 좌측에 48px 폭의 Activity Bar를 신설하여 노트(⌥1), 에이전트(⌥2), 글로벌 리소스(⌥3) 탭과 테마 전환, 설정, 연동 가이드 버튼을 통합 배치했습니다.
  - 패널 영역과 도구 막대를 명확히 분리하고, 불필요한 외곽 마진과 뿌연 오버레이를 제거하여 사이드바가 뷰포트 가장자리에 직각으로 깔끔하게 밀착되도록 개선했습니다.
  - 사이드바 내 불필요한 세로 스크롤바 노출을 숨겨 시각적 잡음을 줄였습니다.
- **아수라다 컴패니언 헤더 카드 및 알림 벨 재배치**
  - 사이드바 상단에 아수라다 브랜드 마크(`LiveBrandMark`, 56px)와 워크스페이스 정보, 알림 벨을 묶은 컴패니언 카드를 배치했습니다.
  - 작업 안내 및 대기 상태를 실시간으로 알릴 수 있는 말풍선 슬롯을 구축했습니다.
- **액티비티 바 아이콘 정렬 및 가독성 개선**
  - 도구 막대 탭 버튼의 아이콘을 픽셀 오차 없이 정중앙에 정렬하고, 설정 아이콘 크기를 20px로 확대해 시각적 균형을 맞췄습니다.
- **상단 탭 바 상단 여백 축소**
  - 상단 탭 바(`TabBar`)의 위쪽 마진을 2px로 축소하여 상단 영역과의 일체감을 강화했습니다.
- **글로벌 리소스 관리 및 프로젝트 서브 리소스 연동**
  - 공통 개발 프로세스 에이전트 및 글로벌 스킬 관리를 위한 전용 탭을 신설하고, 프로젝트별 에이전트/스킬 등록을 사이드바에서 바로 처리할 수 있도록 연동했습니다.
  - 에이전트 탭에서 중복되던 메뉴를 정리해 태스크 중심의 간결한 구조로 정돈했습니다.
- **프롬프트 전송 및 터미널 응답 시 자동 스크롤 개선**
  - 터미널 및 프롬프트 대화 중 새 메시지가 오거나 전송될 때 최하단으로 스크롤되도록 개선했습니다.

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 불필요
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.0.9_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다. 이전 버전이 있으면 덮어씁니다.
3. Applications에서 앱을 실행합니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

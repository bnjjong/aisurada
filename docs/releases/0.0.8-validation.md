## 주요 수정 사항

- **AI 물어보기 팝업 스크롤 격리 및 포커스 점프 수정 ([#107](https://github.com/bnjjong/aisurada/issues/107), [PR #108](https://github.com/bnjjong/aisurada/pull/108))**
  - 팝업 내부 스크롤 시 부모 에디터로 스크롤 이벤트가 전파되어 화면 위아래로 공백이 생기던 현상 해결 (`overscroll-behavior: contain`)
  - 창 전체 고무줄 스크롤 차단 (`html, body { overscroll-behavior: none }`)
  - 팝업 내부 스크롤 시 위치 재계산 무시 필터링
  - 닫기 시 문서 최상단으로 강제 스크롤 점프 방지 (`preventScroll: true`)
- **HTML 프레임 높이 펼치기/접기 토글 ([#105](https://github.com/bnjjong/aisurada/issues/105), [PR #106](https://github.com/bnjjong/aisurada/pull/106))**
- **실제 창 점검 추가**

## 클라우드 빌드

GitHub Actions의 `Build trial release`(macOS arm64 러너)로 검증 및 빌드를 수행했습니다. `bash test.sh`, `bash test-native.sh`, 번들 빌드(`pnpm release:build`)와 번들 검증 10항목이 모두 통과했습니다 ([실행 43987991080](https://github.com/bnjjong/aisurada/actions/runs/43987991080), 11분 25초).

- **번들 검증 10항목:** 앱에 `ais-cli`·라이선스·사용자 안내서가 든다 / Java 런타임과 JAR이 없다 / 번들 버전이 0.0.8이다 / ARM64 앱과 `ais-cli`와 안쪽 코드의 서명 검증 / 번들 `ais-cli`가 한글·공백 경로에 작업 공간을 만든다 / PATH에 아무것도 없이 번들 CLI가 노트를 만들고 따로 뜬 프로세스가 읽는다 / Claude MCP 등록이 번들 `ais-cli`를 가리킨다 / 번들 `ais-cli`가 표준 입출력 MCP를 서비스한다(`initialize`, `tools/list`, `tools/call`) / DMG를 꺼낸 뒤에도 복사한 앱의 엔진 검사가 통한다 / 복사한 DMG 앱이 격리 HOME에서 계속 떠 있다
- **크기:** 앱 32,328KiB, 번들 `ais-cli` 4,554KiB, DMG 14,933,820바이트 (약 14.24 MiB)

# aisurada 0.1.2 — 에이전트 목록 모델 체인 한 줄 표시 개선

Apple Silicon Mac용 `0.1.2` 패치 배포입니다. **설치 파일은 Assets의 `aisurada_0.1.2_aarch64.dmg`입니다.**

0.1.1 이후 에이전트 목록 카드에서 긴 모델명과 추론 강도 조합 시 3순위 칩이 아래 줄로 줄바꿈되던 현상을 해결하고, 항상 한 줄로 깔끔하게 표현되도록 개선한 패치 버전입니다.

## 주요 변경 사항

- **에이전트 목록 카드 모델 체인 칩 한 줄 표시 보장**
  - **줄바꿈 방지 및 한 줄 유지**: `.eng-chain.is-compact`에 `flex-wrap: nowrap`을 적용하여 모델명이나 강도 텍스트 길이에 관계없이 1·2·3순위 칩이 항상 한 줄로 정렬되도록 개선했습니다.
  - **가로 공간 최적화**: 화살표 점선 폭(`14px` → `8px`) 및 칩 여백을 컴팩트하게 조정하여 긴 조합도 자연스럽게 한 줄에 안착되도록 했습니다.
  - **반응형 방어**: 좁은 화면에서도 카드가 깨지지 않도록 `overflow-x: auto` 및 스크롤바 숨김 처리를 적용했습니다.
  - **회귀 방지 테스트 추가**: 컴팩트 체인의 한 줄 배치를 보장하는 단위 테스트를 반영했습니다.

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 불필요 (100% Rust 네이티브 엔진)
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.1.2_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다. 이전 버전이 있으면 덮어씁니다.
3. Applications에서 앱을 실행합니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

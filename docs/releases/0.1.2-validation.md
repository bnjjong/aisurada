## 로컬 릴리즈 빌드 및 번들 검증

`AISURADA_RELEASE_TAG=v0.1.2 pnpm --dir native-host release:build` 명령으로 검증 및 패키징을 수행했습니다. 번들 빌드와 번들 검증 10항목이 모두 통과했습니다.

- **번들 검증 10항목:**
  1. 앱에 `ais-cli`·라이선스·사용자 안내서가 든다
  2. Java 런타임과 JAR이 없다
  3. 번들 버전이 0.1.2이다
  4. ARM64 앱과 `ais-cli`와 안쪽 코드의 서명 검증
  5. 번들 `ais-cli`가 한글·공백 경로에 작업 공간을 만든다
  6. PATH에 아무것도 없이 번들 CLI가 노트를 만들고 따로 뜬 프로세스가 읽는다
  7. Claude MCP 등록이 번들 `ais-cli`를 가리킨다
  8. 번들 `ais-cli`가 표준 입출력 MCP를 서비스한다(`initialize`, `tools/list`, `tools/call`)
  9. DMG를 꺼낸 뒤에도 복사한 앱의 엔진 검사가 통한다
  10. 복사한 DMG 앱이 격리 HOME에서 계속 떠 있다
- **크기:**
  - DMG: 14,972,304 바이트 (약 14.28 MiB)
  - 앱 번들: 32,400 KiB
  - 동봉 CLI (`ais-cli`): 4,553 KiB

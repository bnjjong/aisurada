## 주요 수정 사항

- **C4 요소에 관련 마크다운 노트 연결 (PR #190)**
  - C4 요소(시스템, 컨테이너, 컴포넌트)에 관련 마크다운 노트(최대 50개)를 첨부하고 관리할 수 있습니다.
  - 카드의 노트 뱃지를 클릭하면 캘린더 화면과 동일한 노트 팝업이 뜨며, 여러 개일 경우 목록에서 바로 선택해 열람할 수 있습니다.
  - 상세 패널의 '노트' 섹션과 노트 선택 창(`NotePicker`)을 통해 직관적으로 노트를 붙이고 뗄 수 있습니다.
  - 타임 트래블(Time Travel) 모드에서는 노트를 열람만 할 수 있도록 제한하여 데이터 무결성을 보호합니다.
  - CLI 및 MCP 도구(`apply_c4_changes`)의 `notes` 필드 지원 및 이력 추적을 지원합니다.
- **C4 요소별 맞춤 아이콘 및 76종 테크 로고 지원 (PR #192)**
  - 모든 카드가 종류별 기본 아이콘으로만 표시되던 제약을 해소하고, 요소마다 직관적인 아이콘을 지정할 수 있습니다.
  - 선 아이콘 34종 및 주요 클라우드/테크 서비스의 브랜드 로고 76종(브랜드 컬러 타일)을 지원합니다.
  - 요소 이름/기술 스택을 분석하는 '자동 추천' 단추 및 키워드 실시간 검색 기능을 제공합니다.
  - 엔진, 프론트엔드 UI, MCP 도구 스키마 간 100% 동일한 아이콘 목록을 유지하도록 검증되었습니다.

## 로컬 릴리즈 빌드 및 번들 검증

`AISURADA_RELEASE_TAG=v0.2.9 pnpm --dir native-host release:build` 명령으로 검증 및 패키징을 수행합니다. 번들 빌드와 번들 검증 10항목을 통과합니다.

- **번들 검증 10항목:**
  1. 앱에 `ais-cli`·라이선스·사용자 안내서가 든다
  2. Java 런타임과 JAR이 없다
  3. 번들 버전이 0.2.9이다
  4. ARM64 앱과 `ais-cli`와 안쪽 코드의 서명 검증
  5. 번들 `ais-cli`가 한글·공백 경로에 작업 공간을 만든다
  6. PATH에 아무것도 없이 번들 CLI가 노트를 만들고 따로 뜬 프로세스가 읽는다
  7. Claude MCP 등록이 번들 `ais-cli`를 가리킨다
  8. 번들 `ais-cli`가 표준 입출력 MCP를 서비스한다(`initialize`, `tools/list`, `tools/call`)
  9. DMG를 꺼낸 뒤에도 복사한 앱의 엔진 검사가 통한다
  10. 복사한 DMG 앱이 격리 HOME에서 계속 떠 있다

- **크기:**
  - DMG: 17,362,496 바이트 (약 16.56 MiB)
  - 앱 번들: 37,004 KiB
  - 동봉 CLI (`ais-cli`): 5,678 KiB

# aisurada 0.0.8 — AI 물어보기 팝업 스크롤 격리와 HTML 프레임 높이 조절

Apple Silicon Mac용 `0.0.8` 배포입니다. **설치 파일은 Assets의 `aisurada_0.0.8_aarch64.dmg`입니다.**

0.0.7 이후 발견된 AI 물어보기 문답 팝업의 스크롤 및 포커스 오작동을 수정하고, 본문 내 HTML 프레임의 높이 펼치기/접기 토글 기능을 추가했습니다.

## 주요 변경 사항

- **AI 물어보기 문답 팝업 스크롤 격리 및 닫기 점프 수정 ([#107](https://github.com/bnjjong/aisurada/issues/107), [PR #108](https://github.com/bnjjong/aisurada/pull/108))**
  - **스크롤 체이닝 차단:** 문답 팝업(`AskHoverCard`) 내부에서 휠이나 트랙패드로 스크롤할 때 스크롤 끝에 도달해도 부모 에디터 및 웹뷰 창 전체로 스크롤 이벤트가 전파되지 않도록 `overscroll-behavior: contain;`을 적용했습니다. 이로 인해 본문 위아래로 배경색 공백이 노출되던 문제가 해결되었습니다.
  - **고무줄 스크롤 방지:** 창 전체에 `overscroll-behavior: none;`을 지정하여 macOS 웹뷰의 고무줄 바운스(Elastic Scroll / Rubber-banding)를 차단했습니다.
  - **위치 재계산 필터링:** 팝업 내부 스크롤 시에는 팝업 좌표 갱신 리스너를 건너뛰어 카드가 튀거나 텍스트가 잘리는 현상을 방지했습니다.
  - **닫기 시 스크롤 위치 보존:** 팝업을 닫을 때 이전 포커스 복원 과정에서 화면이 문서 최상단으로 강제 점프하던 현상을 수정했습니다(`preventScroll: true` 적용).
- **HTML 프레임 높이 펼치기/접기 토글 ([#105](https://github.com/bnjjong/aisurada/issues/105), [PR #106](https://github.com/bnjjong/aisurada/pull/106))**
  - 본문에 들어간 HTML 프레임 박스의 높이를 필요에 따라 펼치거나 접을 수 있는 버튼과 동작을 추가했습니다.
- **실제 창 점검 추가 및 안정성 강화**
  - 기존에 커버되지 않던 화면들에 대한 실제 WKWebView 창 점검을 추가하여 전반적인 렌더링 안정성을 높였습니다.

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 불필요
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.0.8_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다. 이전 버전이 있으면 덮어씁니다.
3. Applications에서 앱을 실행합니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

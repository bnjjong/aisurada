# aisurada 0.0.3 — 기능 개선 및 안정화 배포

Apple Silicon Mac용 `0.0.3` 배포입니다. **설치 파일은 Assets의 `aisurada_0.0.3_aarch64.dmg`입니다.**

## 주요 변경 사항

- **아젠다 화면 및 좌측 레일(Rail) 선택 연동**: 아젠다 진입 시 상단 메뉴의 캘린더 선택 효과를 끄고, 실제 열람 중인 아젠다 항목에 선택(active) 하이라이트를 표시하도록 개선했습니다.
- **노트 미리보기(Preview) 창 너비 확장 연동**: 미리보기 모달 창 크기를 마우스로 늘릴 때 내부 본문 컨텐츠 가로폭이 창 크기에 맞추어 자연스럽게 확장되도록 개선했습니다.
- **HTML 프레임 헤더 액션 정렬**: HTML 첨부 뷰어 상단 헤더 액션 버튼들을 우측으로 정렬하여 본문 가독성을 높였습니다.
- **AI CLI 연동 확장 (Google Antigravity & Gemini CLI 지원)**: 기존 Claude CLI 외에 Google Antigravity CLI(`antigravity -p`) 및 Gemini CLI를 지원하며, 모델 선택을 간소화(Gemini 3.8 Flash High/Medium, Claude Opus 5.5 / Sonnet 5.5)했습니다.
- **노트 본문 AI 묻기 팝오버 좌표 보정**: 본문 텍스트 드래그 시 AI 묻기 입력 팝오버가 텍스트 선택 영역 바로 옆에 정확히 배치되도록 보정했습니다.
- **사이드바 워크스페이스 실제 경로 표시**: 좌측 사이드바 레일의 워크스페이스 명칭 아래에 실제 연결된 볼트(저장소) 폴더 경로를 표시합니다.
- **구조 통일 및 경계 방어/동시성 보호**: 동시 쓰기 충돌 방지 및 안전한 파일 입출력 가드를 강화했습니다.
- **터미널 스크롤백 고정(Pin) 모달 복원**: 터미널 출력 굳히기(핀) 모달 배경 및 Claude 연동 모듈 안정성을 확보했습니다.
- **편집기 및 호스트 안정성 대폭 강화**:
  - HTML 첨부 문서(iframe) 로드 복원 및 외부 주소 스푸핑 차단
  - 메인 창 종료 시 열려 있는 독립 노트 창의 미저장 글 유실 방지
  - 마크다운 표 칸 구두점 앞 역슬래시(경로 및 정규식) 이중 unescape 방지
  - 세션 전사 캐시 결함 및 대용량 메모리 누수 해소
  - 라이트 테마에서 주요 버튼(`.btn-primary`) 마우스 호버 시 글자 사라짐 해결
  - macOS Finder 별칭 파일 우회 실행 차단
  - YAML 접는 블록(`>-`) 빈 줄 개행 소실 버그 해결 및 코드 블록 내 코멘트 마커 오염 방지

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 21 런타임 동봉: Java 별도 설치 불필요
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.0.3_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다.
3. Applications에서 앱을 실행합니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

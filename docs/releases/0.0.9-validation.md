## 주요 수정 사항

- **IntelliJ 스타일 도구 막대(Activity Bar 48px) 도입 및 사이드바 전면 개편**
- **아수라다 브랜드 마크 공간 복원 및 컴패니언 헤더 카드/알림 벨 재배치**
- **사이드바 외곽 마진·뿌연 틴트 제거 및 세로 스크롤바 숨김 (패널 완전 밀착)**
- **액티비티 바 탭 아이콘 정중앙 정렬 및 설정 아이콘 20px 확대**
- **상단 탭 바 위쪽 여백 마진 2px 축소**
- **글로벌 리소스 관리 화면 구축 및 프로젝트 사이드바 서브 리소스 연동**
- **프롬프트 전송 및 터미널 응답 시 자동 스크롤 개선**

## 클라우드 빌드

GitHub Actions의 `Build trial release`(macOS arm64 러너)로 검증 및 빌드를 수행했습니다. `bash test.sh`, `bash test-native.sh`, 번들 빌드(`pnpm release:build`)와 번들 검증 10항목이 모두 통과했습니다 ([실행 44027090122](https://github.com/bnjjong/aisurada/actions/runs/44027090122), 14분 19초).

- **번들 검증 10항목:** 앱에 `ais-cli`·라이선스·사용자 안내서가 든다 / Java 런타임과 JAR이 없다 / 번들 버전이 0.0.9이다 / ARM64 앱과 `ais-cli`와 안쪽 코드의 서명 검증 / 번들 `ais-cli`가 한글·공백 경로에 작업 공간을 만든다 / PATH에 아무것도 없이 번들 CLI가 노트를 만들고 따로 뜬 프로세스가 읽는다 / Claude MCP 등록이 번들 `ais-cli`를 가리킨다 / 번들 `ais-cli`가 표준 입출력 MCP를 서비스한다(`initialize`, `tools/list`, `tools/call`) / DMG를 꺼낸 뒤에도 복사한 앱의 엔진 검사가 통한다 / 복사한 DMG 앱이 격리 HOME에서 계속 떠 있다
- **크기:** DMG 14,940,661바이트 (약 14.25 MiB)

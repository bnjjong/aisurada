# aisurada 0.2.2 — 설정 화면 6대 카테고리 재편 및 프로젝트 매니저 연동

Apple Silicon Mac용 `0.2.2` 패치 배포입니다. **설치 파일은 Assets의 `aisurada_0.2.2_aarch64.dmg`입니다.**

0.2.1 이후 **설정 화면 6대 카테고리 전면 재배치 및 실시간 검색**, **프로젝트 매니저(Hermes / Slack 웹훅) 연동**, **공유 텍스트 비교 뷰(Diff View)** 및 **스킨별 UI/접근성 개선**을 포함하는 패치 업데이트입니다.

## 주요 변경 사항

- **설정 화면 6대 카테고리 재편 및 실시간 검색 지원**
  - **6개 묶음 재배치**: 방대해진 설정을 모양(`look`), 글꼴(`fonts`), 노트(`notes`), 알림(`notifications`), AI(`ai`), 연결(`connections`)의 6개 묶음으로 직관적으로 재구성했습니다.
  - **실시간 설정 검색 및 키보드 탐색**: 좌측 네비게이션 상단 검색창에서 17개 설정 항목을 즉시 검색할 수 있으며, 방향키(위/아래/왼쪽/오른쪽)와 Home/End 키로 탭 목록을 순환 탐색할 수 있습니다.
  - **시스템 글꼴 감지 및 추천 칩**: 캔버스 2D 기반으로 설치된 글꼴을 실시간 감지하여 칩 형태로 바로 선택할 수 있습니다.
  - **스킨 호환성 및 대비 강화**: 격자 스킨의 각진 네모 손잡이(14px)와 모던 스킨의 고유 형태를 완벽히 격리 보존하고, 기본 모양(classic)의 선택 탭과 꺼진 스위치 홈에 WCAG 3:1 대비를 충족하는 테두리 및 악센트 스타일을 적용했습니다.
- **프로젝트 매니저(Hermes / Slack 웹훅) 연동**
  - **프로젝트별 매니저 인테이크**: 프로젝트 범위로 자율 에이전트 매니저를 연결하고 관리할 수 있습니다.
  - **전용 매니저 관리 화면**: 에이전트 탭 내 「매니저」 화면(`ManagersPage`, `ManagerSetup`)에서 웹훅 URL, 프로젝트 매핑 및 알림 설정을 손쉽게 구성할 수 있습니다.
  - **태스크 진행 상태 및 리포트 실시간 알림**: 태스크 생성, 상태 전이 및 완료 리포트 링크를 Slack 등으로 실시간 전송합니다.
- **공유 텍스트 비교 뷰(Diff View) 통합**
  - `@pierre/diffs` 라이브러리를 기반으로 통합 `DiffBody` 컴포넌트를 구축하여 노트 변경 이력과 코드 비교의 가독성을 높였습니다.
- **Archyl 프로젝트 브라우저 바로가기**
  - 선택된 Archyl 소프트웨어 아키텍처 프로젝트의 클라우드 웹 콘솔로 즉시 이동할 수 있는 브라우저 링크를 제공합니다.

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 불필요 (100% Rust 네이티브 엔진)
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.2.2_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다. 이전 버전이 있으면 덮어씁니다.
3. Applications에서 앱을 실행합니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

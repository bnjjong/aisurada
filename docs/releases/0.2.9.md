# aisurada 0.2.9 — C4 요소별 노트 연결 및 커스텀 로고/아이콘 지원 패치

Apple Silicon Mac용 `0.2.9` 패치 배포입니다. **설치 파일은 Assets의 `aisurada_0.2.9_aarch64.dmg`입니다.**

0.2.8 이후 **C4 요소에 마크다운 노트 연결 및 카드 내 바로보기**, **요소별 맞춤 선 아이콘 및 76종 브랜드 로고 타일 지원**을 포함하는 기능 고도화 패치 업데이트입니다.

## 주요 변경 사항

- **C4 요소에 관련 마크다운 노트 연결 (PR #190)**:
  - C4 요소(시스템, 컨테이너, 컴포넌트)에 관련 마크다운 노트(최대 50개)를 첨부하고 관리할 수 있습니다.
  - 카드의 노트 뱃지를 클릭하면 캘린더 화면과 동일한 노트 팝업이 뜨며, 여러 개일 경우 목록에서 바로 선택해 열람할 수 있습니다.
  - 상세 패널의 '노트' 섹션과 노트 선택 창(`NotePicker`)을 통해 직관적으로 노트를 붙이고 뗄 수 있습니다.
  - 타임 트래블(Time Travel) 모드에서는 노트를 열람만 할 수 있도록 제한하여 데이터 무결성을 보호합니다.
  - CLI 및 MCP 도구(`apply_c4_changes`)의 `notes` 필드 지원 및 이력 추적을 지원합니다.

- **C4 요소별 맞춤 아이콘 및 76종 테크 로고 지원 (PR #192)**:
  - 모든 카드가 종류별 기본 아이콘으로만 표시되던 제약을 해소하고, 요소마다 직관적인 아이콘을 지정할 수 있습니다.
  - 선 아이콘 34종 및 주요 클라우드/테크 서비스의 브랜드 로고 76종(브랜드 컬러 타일)을 지원합니다.
  - 요소 이름/기술 스택을 분석하는 '자동 추천' 단추 및 키워드 실시간 검색 기능을 제공합니다.
  - 엔진, 프론트엔드 UI, MCP 도구 스키마 간 100% 동일한 아이콘 목록을 유지하도록 검증되었습니다.

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 불필요 (100% Rust 네이티브 엔진)
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.2.9_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다. 이전 버전이 있으면 덮어씁니다.
3. Applications에서 앱을 실행합니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

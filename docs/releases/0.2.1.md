# aisurada 0.2.1 — Archyl C4 네이티브 캔버스 및 다이어그램 연동

Apple Silicon Mac용 `0.2.1` 패치 배포입니다. **설치 파일은 Assets의 `aisurada_0.2.1_aarch64.dmg`입니다.**

0.2.0 이후 **Archyl C4 소프트웨어 아키텍처** 클라우드 모델 연동 및 전용 인터랙티브 카드 캔버스 뷰어 탑재, **Draw.io 다이어그램** 인라인 임베드 및 줌/팬 지원, **아젠다 하위 분류(Subcategories)** 필터링과 **태스크 오케스트레이터** 연계를 포함하는 패치 업데이트입니다.

## 주요 변경 사항

- **Archyl C4 아키텍처 연동 및 네이티브 인터랙티브 캔버스 뷰어 탑재**
  - **Archyl 클라우드 모델 연동**: API 키 및 MCP를 통해 Archyl C4 아키텍처 모델을 데스크톱 앱 내에서 직접 조회하고 프로젝트 노트와 연결할 수 있습니다.
  - **네이티브 카드 캔버스 뷰어(`ArchylCanvas`) 구현**: 기존 Mermaid 텍스트 변환 방식 대신 Archyl 웹 콘솔(app.archyl.com)과 100% 동일한 도트 그리드 배경, Person 타원형 아바타, System/External 뱃지 카드 디자인 및 부드러운 SVG 3차 베지어 곡선 커넥터와 라벨 Pill 렌더링을 지원합니다.
  - **실시간 위치 동기화 및 줌/팬**: 마우스 드래그를 통해 카드를 이동하면 Archyl 클라우드에 실제 2D 좌표(`update_positions`)가 실시간으로 저장되며, 휠 줌(0.4x ~ 2.2x) 및 패닝 조작을 제공합니다.
  - **C4 다이어그램-채팅 연계**: C4 다이어그램 요소와 AI 에이전트 대화(Chat)를 상호 참조할 수 있도록 연결했습니다.
- **Draw.io 다이어그램 임베드 및 인라인 뷰어/편집기 지원**
  - **노트 내 Draw.io 임베드**: 마크다운 노트 본문에 Draw.io 다이어그램을 삽입하고 깔끔하게 렌더링합니다.
  - **인라인 조작 및 단축키**: 다이어그램 본문 너비 맞춤 기본화, 인라인 줌 및 팬 컨트롤 바, 키보드 단축키를 제공합니다.
- **아젠다 하위 분류(Subcategories) 및 노트 탐색 고도화**
  - 아젠다 하위 분류별로 노트를 필터링하고 탭 전환 시에도 필터 상태를 안정적으로 유지합니다.
  - 노트 미리보기 팝업에서도 아젠다를 즉시 수정할 수 있도록 지원합니다.
- **태스크 오케스트레이터 연동 및 타임스탬프 필드 보장**
  - 태스크 실행 시 자율 에이전트 개발·검사·리뷰 오케스트레이터와 연결하여 작업을 수행합니다.
  - 리소스 및 태스크 엔티티의 생성 시각(`createdAt`)과 수정 시각(`editedAt`) 누락 방지 및 엄격한 검증을 적용했습니다.

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 불필요 (100% Rust 네이티브 엔진)
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.2.1_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다. 이전 버전이 있으면 덮어씁니다.
3. Applications에서 앱을 실행합니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

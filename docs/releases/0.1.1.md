# aisurada 0.1.1 — 모델 체인 시각화 개선, 공식 로고 적용 및 모달·스크롤 안정화

Apple Silicon Mac용 `0.1.1` 패치 배포입니다. **설치 파일은 Assets의 `aisurada_0.1.1_aarch64.dmg`입니다.**

0.1.0 정식 릴리즈 이후 AI 실행 엔진 모델 체인 시각화와 각 AI 브랜드 공식 로고를 정밀 적용하고, 모달 크기 조절 손잡이 분리, 노트 탭 스크롤 포커스 복원, `create_task` MCP 도구 문서를 보강한 패치 버전입니다.

## 주요 변경 사항

- **AI 엔진 모델 체인 시각화 및 로고 표준화**
  - **에이전트 목록 모델 체인 칩(compact chips) 적용**: 에이전트 목록 카드에서 1·2·3순위 AI 모델 체인을 상자형 배지 대신 간결한 칩 형태로 통일하여 한눈에 확인할 수 있도록 개선했습니다. (2순위·3순위가 설정된 경우에만 해당 칩 노출)
  - **체인 요약 엔진 로고(bare) 표시**: 모델 체인 요약(팝업 및 목록 카드)에서 색상 타일 박스를 걷어내고 엔진 고유 아이콘만 시원하게 표시하도록 개선했습니다.
  - **공식 Claude 로고 윤곽선 적용**: 기존 근사형 8개 살 아이콘 대신 12개 살의 공식 Claude 로고 윤곽선과 브랜드 컬러(`#d97757`)를 적용했습니다.
  - **공식 OpenAI 로고로 Codex 마크 교체**: Codex 마크를 OpenAI 공식 로고 윤곽선으로 교체하여 식별성을 강화했습니다.
  - **모델별 최대 추론 강도(effortLevel) 비례 계산 개선**: Gemini 3.8 Flash 등 지원 강도가 5단계 미만(low, medium, high 3단계)인 모델도 최고 강도 선택 시 5칸 게이지가 꽉 차도록(low 1칸, medium 3칸, high 5칸) 펼쳐서 표시합니다.
- **모달 크기 조절 손잡이 레이아웃 안정화 (내용 겹침 해결)**
  - 승인 대기함 등 크기 조절 모달에서 우하단 리사이즈 손잡이가 본문 액션 버튼(승인 등)과 겹치거나 스크롤 시 위로 딸려 올라가는 현상을 방지하기 위해 스크롤 영역과 손잡이 전용 하단 띠(`ui-modal-gripbar`)를 구조적으로 분리했습니다.
  - 손잡이 띠 도입에 맞춰 승인 대기함 모달 기본 높이를 최적화하고 글래스 스킨 스타일을 정돈했습니다.
- **노트 탭 키보드 탐색 및 스크롤 포커스 복원**
  - 노트 탭 전환 시 새로 렌더링된 본문 스크롤 영역에 포커스를 안정적으로 이동하고 마지막 스크롤 위치를 복원하도록 개선했습니다.
  - 탭 표시줄을 키보드 화살표로 탐색하는 중에도 PageUp/PageDown 키 입력 시 본문 스크롤 영역으로 자연스럽게 포커스가 이전됩니다.
- **`create_task` MCP 도구 문서 동기화**
  - MCP 서버에 새로 추가된 태스크 등록 쓰기 도구 `create_task`를 개발자 가이드, README, MCP 가이드에 반영하고 도구 수치(기본 19개, 쓰기 모드 38개, 엔진 도구 39개)를 일원화했습니다.

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 불필요 (100% Rust 네이티브 엔진)
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.1.1_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다. 이전 버전이 있으면 덮어씁니다.
3. Applications에서 앱을 실행합니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

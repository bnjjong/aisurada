# aisurada 0.0.7 — Java 없이 도는 엔진, 태스크와 승인, 새 화면 설정

Apple Silicon Mac용 `0.0.7` 배포입니다. **설치 파일은 Assets의 `aisurada_0.0.7_aarch64.dmg`입니다.**

0.0.6 이후 가장 큰 변화는 엔진입니다. 노트를 읽고 쓰는 엔진이 Rust로 바뀌어 앱 안에서 직접 돌고, **Java 런타임이 앱에서 빠졌습니다.** 노트·태스크·스킬 파일의 형식은 그대로입니다. 여기에 태스크 보드와 알림, AI가 쓴 스킬·에이전트 변경의 승인 절차, 좌측 메뉴 두 탭, 글꼴·화면 크기 설정이 더해졌습니다.

## 주요 변경 사항

- **엔진이 Rust로 바뀌고 Java가 사라졌습니다.**
  - 앱이 엔진을 따로 띄우지 않고 앱 안에서 바로 부릅니다. Java 런타임이 들어 있지 않아 설치 파일이 약 15MB로 줄었습니다(0.0.6은 약 60MB). Java를 따로 설치할 필요도 없습니다.
  - AI에게 노트를 열어 주는 `ais-cli`(MCP 서버 포함)도 같은 Rust 실행 파일입니다. 앱 번들 안에 들어 있습니다.
  - **첫 실행에서 한 번 자동으로 정리합니다.** 이전 판이 띄워 둔 백그라운드 엔진(launchd 항목)을 내리고, Java 시절 파일을 가리키는 낡은 MCP 등록(Claude Code, Codex, Gemini)은 같은 에이전트에 다시 등록합니다. 손으로 하려면 터미널에서 `ais-cli doctor --fix`를 씁니다. 「Claude 연결」 화면은 낡은 등록을 표시해 줍니다.
  - 파일 형식은 그대로입니다. 새 엔진이 옛 Java 엔진과 같은 명령에서 같은 응답과 같은 파일 내용(글자 단위)을 내는지 맞대어, 어긋남이 없었습니다.
- **태스크와 알림이 생겼습니다.**
  - 일을 티켓(태스크)으로 적어 두고 보드, 목록, 상세 화면에서 상태·유형·저장소·라벨로 다룹니다. 태스크는 vault의 `.aisurada/tasks/` 아래에 파일로 남습니다.
  - 알림 센터와 macOS 배너로 질문, 보고, 실패, 승인 요청을 알려 줍니다. 설정에서 시험 알림을 보낼 수 있습니다.
  - **읽기 전용 러너.** 상태가 Ready For Develop인 태스크를 앱이 집어 Claude에게 저장소와 노트를 읽게만 하고, 조사 결과를 댓글로 남겨 In Review로 보내거나 사람만 답할 수 있는 질문을 남겨 Waiting Answer로 보냅니다. 앱이 켜져 있는 동안에만 돌고, 코드를 고치거나 PR을 올리지는 않습니다.
- **AI가 쓴 스킬·에이전트 변경은 승인을 거칩니다.** AI가 스킬·에이전트 정의를 고치면 정책에 따라 바로 적용하거나 「대기 변경」으로 올립니다. 에이전트 권한을 올리거나 도구 칸을 바꾸거나 참조를 켜는 일은 늘 승인이 필요합니다. 승인함, 레일 배지, 알림에서 사람이 승인하거나 거절합니다. 사람이 앱에서 직접 낸 변경은 그대로 적용됩니다.
- **화면이 바뀌었습니다.**
  - 좌측 메뉴(레일)가 「노트」와 「에이전트」 두 탭으로 나뉩니다. `Option+1`, `Option+2`로 전환합니다.
  - 후속 노트(하위 페이지)를 모달 대신 탭으로 엽니다.
  - 설정에 「글꼴과 크기」가 생겨 화면 배율과 글꼴을 고를 수 있습니다.
  - 입력 칸의 가로 스크롤바가 사라지고, 노트 코멘트 목록과 입력 칸이 전체 너비를 씁니다.
- **AI 쓰기 보호가 단단해졌습니다.**
  - AI는 기계가 남긴 「기록 층」 노트를 고치지 못하고, 코멘트·휴지통 도구로도 볼 수 없습니다.
  - 앱과 AI 도구가 같은 vault에 동시에 써도 서로 덮어쓰지 않도록 쓰기 잠금을 프로세스 사이에서 함께 씁니다. `commit_vault`도 이 잠금을 잡습니다.
  - 앱이 닫혀 있는 동안 명령줄이 남긴 자동 커밋 대기 기록은 다음에 앱이 열릴 때 이어받아 커밋합니다.
- 엔진 안쪽 구조를 크게 정리했습니다(여러 크레이트로 나눔). 동작은 바뀌지 않았고 사용자에게 보이는 변화는 없습니다.

## 알려진 문제

- **새 화면은 실제 앱 창에서 손으로 눌러 본 확인이 일부뿐입니다.** 태스크 보드, 러너, 승인함, 레일 탭, 후속 노트 탭, 글꼴 설정은 자동 점검(실제 WKWebView 창 10종, 화면·호스트 시험)으로 확인했습니다. 사람이 손으로 확인하는 일은 [이슈 #54](https://github.com/bnjjong/aisurada/issues/54)에서 이어 갑니다.
- **새 화면과 승인 절차의 사용법은 사용자 안내서에 아직 없습니다.** 안내서는 노트·검색·세션·설정 같은 기존 기능 위주입니다.
- 러너는 읽기 전용이고 앱이 켜져 있는 동안에만 돕니다.
- 깨끗한 Mac에서 Finder로 설치해 본 확인이 없고, Apple 공증은 받지 않았습니다.
- 0.0.6에서 알려진 것으로 이번에 고치지 않은 것: 프로젝트를 지워도 그 프로젝트의 스킬·에이전트 폴더(`.aisurada/resources/projects/<프로젝트>`)가 남습니다. 0.0.4 이하 버전이 0.0.5 이후 버전이 만든 노트를 다시 쓰면 머리말의 `sessionAgent`, `editedSessionAgent` 줄이 지워질 수 있습니다. GitHub App 연결은 공개 저장소로만 확인했습니다. Antigravity 대화는 시스템 `sqlite3`로 읽고 도구 결과는 보이지 않습니다. 세션 목록 화면에는 Codex·Gemini 세션이 나오지 않습니다.

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 불필요
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.0.7_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다. 이전 버전이 있으면 덮어씁니다.
3. Applications에서 앱을 실행합니다. 첫 실행에서 위의 자동 정리가 한 번 돕니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

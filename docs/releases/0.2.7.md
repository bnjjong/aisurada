# aisurada 0.2.7 — C4 아키텍처 다이어그램 인터랙션 및 UX 고도화 패치

Apple Silicon Mac용 `0.2.7` 패치 배포입니다. **설치 파일은 Assets의 `aisurada_0.2.7_aarch64.dmg`입니다.**

0.2.6 이후 **C4 아키텍처 다이어그램 인터랙션 및 시각적 가독성 전면 개선**, **관계선 드래그 연결 및 포트 기억 기능**, **상세 패널 우측 플로팅 카드화**, **관계 라벨 드래그 이동 및 뷰 좌표 저장**을 포함하는 패치 업데이트입니다.

## 주요 변경 사항

- **C4 다이어그램 카드 디자인 및 가독성 개편 (PR #173, #175, #177)**:
  - 카드 시각 계층 구조 개선(아이콘 뱃지, 종류 라벨, 설명, 기술 스택) 및 테두리/그림자 다듬기.
  - 카드를 확대하거나 축소할 때 텍스트가 번지지 않도록 최종 화면 크기로 선명하게 렌더링.
  - 화살표 머리와 관계선 굵기, 색상 대비를 정돈하여 전체 캔버스를 균형 있게 채움.

- **포인터 중심 마우스 휠 줌 및 확대 비례 라벨 스케일링 (PR #174, #180)**:
  - 마우스 휠 및 트랙패드 핀치로 포인터 위치를 축 삼아 부드럽게 확대/축소.
  - 배율에 따라 관계 라벨 글자 크기 및 여백이 카드와 비례하여 커져 작은 글씨가 뭉개지지 않음.

- **드래그 앤 드롭 관계선 연결 및 12개 연결 지점(포트) 지원 (PR #176, #178, #183)**:
  - 카드 가장자리의 포트를 마우스로 끌어 다른 카드에 놓는 방식으로 관계선을 직관적으로 생성.
  - 기존 상·하단 3개 포트에 더해 **좌·우 변에도 위/아래 포트를 2개씩 추가(각 변마다 3개씩, 총 12개 포트)**하여 대칭적이고 유연한 다이어그램 구성 지원.
  - 선 끝 손잡이를 드래그하여 다른 카드나 같은 카드의 다른 포트로 쉽게 재연결.
  - 연결된 포트 위치(`sourcePort`, `targetPort`)를 모델에 저장하여 다이어그램 배치 보존.

- **우측 상단 플로팅 상세 정보 패널 (PR #181)**:
  - 기존 하단 고정 바 형태의 상세 패널을 캔버스 우측 상단 플로팅 카드로 이동.
  - 선택된 요소/관계가 있을 때만 공간을 차지하며 나타나고, 헤더 우측 상단 닫기(X) 버튼 제공.
  - 설명, 기술 스택, 코드 참조, 연결된 관계 목록 및 주요 액션 버튼을 섹션별로 정돈.

- **관계선 라벨 드래그 이동 및 뷰별 좌표 저장 (PR #182)**:
  - 엣지 라벨(`.c4-edge`)을 마우스로 끌어 원하는 위치로 자유롭게 이동.
  - 라벨이 선에서 떨어져 이동하면 베지어 곡선 위의 최단 지점과 라벨 중심을 잇는 지시선(Leader line)이 실시간으로 렌더링.
  - 이동된 라벨의 월드 좌표가 `views.yaml`의 뷰 좌표에 안전하게 영구 저장.

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 불필요 (100% Rust 네이티브 엔진)
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.2.7_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다. 이전 버전이 있으면 덮어씁니다.
3. Applications에서 앱을 실행합니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

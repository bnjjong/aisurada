# aisurada 0.2.4 — 엔진·호스트·화면 아키텍처 리팩토링 및 안정화 패치

Apple Silicon Mac용 `0.2.4` 패치 배포입니다. **설치 파일은 Assets의 `aisurada_0.2.4_aarch64.dmg`입니다.**

0.2.3 이후 **엔진·호스트·화면 전반의 20대 종합 리팩토링 통합**과 **인테이크 및 첨부파일 안정화**를 포함하는 패치 업데이트입니다.

## 주요 변경 사항

- **엔진 모듈 분할 및 아키텍처 경계 안정화**:
  - `doc_write` 및 `resource_commands` 모듈 분할(`place`, `retag`, `warning`, `change`, `crud`, `policy`, `ref_cmd`)로 단일 책임 원칙 강화.
  - `note` 모듈 내 도메인 엔티티 복원 및 아키텍처 규칙 베이스라인 경계(`note` -> `kernel` 간접화) 수호.
  - 골든 테스트 러너 스크립트 정비 및 최신 엔진 피처 골든 테스트 자동 검증 기반 마련.
  - 중복 소형 헬퍼 및 미사용 코드 전면 정리.

- **호스트 및 IPC 통신 계층 정비**:
  - `engineClient.ts` 도입: `EngineCall`, `explainEngineError`, `createExternalStore`로 client와 store 공통 섀시 표준화.
  - `StandardErrorKind` 표준 에러 분류 및 `extractErrorKind` 도입으로 에러 핸들링과 한국어 피드백 일관성 강화.
  - `FullPreferences` 결합 모델 도입으로 뷰-스토리지 간 불필요한 이중 타입 캐스팅 제거.
  - 호스트 명령어 맵(`hostCommands.ts`) 분리 및 프로세스 대기 로직 단일화.

- **화면(UI) 및 부가 기능 개선**:
  - 팝오버 닫기 훅(`usePopoverDismiss`) 통합으로 코드 중복 제거 및 상호작용 안정성 향상.
  - HTML 첨부파일 높이 안정화 (PR #157).
  - 인테이크(Intake) 디자인 완성 및 매니저 인테이크 레코드 격리 (PR #155, #156).
  - 슬랙 인테이크 커서 추적 (PR #154).
  - 퀵 서치 서브노트 ID 검색 지원 (PR #153).

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 불필요 (100% Rust 네이티브 엔진)
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.2.4_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다. 이전 버전이 있으면 덮어씁니다.
3. Applications에서 앱을 실행합니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

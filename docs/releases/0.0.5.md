# aisurada 0.0.5 — 프로젝트 저장소, 스킬·에이전트 정의, Codex·Gemini 세션 연동

Apple Silicon Mac용 `0.0.5` 배포입니다. **설치 파일은 Assets의 `aisurada_0.0.5_aarch64.dmg`입니다.**

0.0.4 이후에 만든 세 가지 기능을 묶은 배포입니다. 프로젝트가 저장소를 갖게 되었고, 스킬과 에이전트 정의를 앱에서 다룰 수 있게 되었고, 노트에 적힌 Codex·Gemini 세션을 앱에서 바로 열 수 있게 되었습니다.

## 주요 변경 사항

- **프로젝트가 저장소를 가집니다.**
  - 프로젝트에 로컬 폴더나 GitHub 저장소(또는 둘 다)를 여러 개 연결하고, 아젠다가 그중 하나를 고를 수 있습니다.
  - 설정에서 GitHub App의 App ID와 개인 키(PEM)를 등록하면 앱이 설치된 저장소 목록을 읽어 옵니다. 개인 키는 키체인에만 두고 화면으로 되돌려 보내지 않습니다.
  - 저장소 편집기 옆의 안내 팝업이 이 저장소가 어떻게 쓰이고 관리되는지 그림 세 장으로 설명합니다.
  - 왼쪽 레일은 프로젝트를 맨 위에 두고 아젠다를 그 안쪽에 묶어 보여 줍니다. 세션 목록이던 PROJECTS 패널은 쓰임이 없어 없앴습니다.
- **스킬과 에이전트 정의를 자원으로 다룹니다.**
  - 글로벌 자원과 프로젝트 자원 두 곳에서 관리하고, 프로젝트는 참조한 글로벌 자원만 씁니다. 참조하지 않은 것은 쓰이지 않습니다. 자원마다 고유 ID가 있고 참조는 ID로 겁니다.
  - 왼쪽 메뉴 「스킬·에이전트」(글로벌)와 레일의 「프로젝트 페이지」에서 만들고, 고치고, 지우고, 되살립니다. 고칠 때마다 이력이 남고 30개까지 되돌릴 수 있습니다.
  - 에이전트를 참조하면 그 에이전트가 필요로 하는 스킬을 보여 주고 함께 참조할지 묻습니다. 참조하던 글로벌 자원을 지우면 프로젝트에 「깨진 참조」로 알려 줍니다.
  - MCP 도구 8개(`list_resources` 등)로 AI도 읽고 쓸 수 있습니다. 쓰는 도구는 쓰기 모드로 등록했을 때만 열립니다.
- **Codex·Gemini 세션을 노트에서 바로 엽니다.**
  - 노트 머리말에 세션을 연 CLI(`sessionAgent`)를 함께 적고, 세션 칩은 Claude Code, Codex, Gemini CLI 중 어느 CLI의 세션인지 늘 이름을 보입니다.
  - 칩의 「터미널」 단추로 앱 터미널 탭에서 그 세션을 이어 엽니다. Codex와 Gemini의 대화 기록은 세션 화면과 대화 패널에서 읽기 전용으로 볼 수 있습니다.
  - Antigravity(`agy`)로 연 대화도 세션 id로 찾아 읽고, `agy --conversation`으로 이어 엽니다.
  - Gemini CLI는 세션 id를 MCP 서버에 주지 않아서, 세션 id를 넘겨 주는 실행 래퍼 `ais-gemini`를 더했습니다.
  - 에이전트의 MCP 서버와 `ais-cli`가 호출할 때마다 앱이 연 vault를 따릅니다. 손 확인용 vault가 남아 있어도 노트가 엉뚱한 vault에 쓰이지 않습니다.
- **화면을 다듬었습니다.** 세션 입력창을 흰 카드 한 장으로 다시 그렸고, 세션 레일이 노트 본문 오른쪽에 뜨도록 고쳤습니다. 0.0.4의 알려진 문제였던 충돌 화면 확인 창 문구(「첨부 열기」)를 바로잡았습니다.

## 알려진 문제

- **스킬·에이전트의 권한 값은 아직 쓰이지 않습니다.** 읽기·수정·공개 권한을 저장하지만 어디에도 적용하지 않습니다. AI가 쓴 변경(참조와 권한 포함)은 승인 없이 바로 적용되고, 이력으로만 되돌릴 수 있습니다. 승인 흐름은 [이슈 #53](https://github.com/bnjjong/aisurada/issues/53)에서 이어 갑니다.
- 프로젝트를 지워도 그 프로젝트의 스킬·에이전트 폴더(`.aisurada/resources/projects/<프로젝트>`)는 남습니다.
- GitHub App 연결은 공개 저장소로만 확인했습니다. 비공개 저장소를 받아 오는 것은 확인하지 못했습니다.
- Antigravity 대화는 시스템의 `sqlite3`(macOS 기본)로 읽습니다. Antigravity가 내용을 비워 둔 오래된 단계는 보이지 않고, 도구 결과는 보이지 않습니다. 세션 칩에는 Gemini CLI와 같은 「Gemini CLI」로 나옵니다.
- 세션 목록 화면에는 Codex·Gemini 세션이 나오지 않고, 노트 칩으로 들어간 세션 화면은 읽기 전용입니다.
- 이번에 더한 화면(「스킬·에이전트」, 프로젝트 페이지)은 실제 앱 창에서 손으로 눌러 본 확인이 없습니다. 모의 엔진을 쓰는 화면 시험과 엔진·호스트 시험으로만 확인했습니다. Antigravity의 「터미널」 이어 열기는 배포 뒤 실제 앱에서 눌러 이어 열리는 것을 확인했습니다.
- 0.0.4 이하 버전이 이 버전에서 만든 노트를 다시 쓰면 머리말의 `sessionAgent`, `editedSessionAgent` 줄이 지워질 수 있습니다.

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 21 런타임 동봉: Java 별도 설치 불필요
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.0.5_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다. 이전 버전이 있으면 덮어씁니다.
3. Applications에서 앱을 실행합니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

# aisurada 0.0.2 — 안정화 배포

Apple Silicon Mac용 `0.0.2` 배포입니다. **설치 파일은 Assets의 `aisurada_0.0.2_aarch64.dmg`입니다.**

## 주요 변경 사항

- **노트 이미지 파일명 캡션 표시**: 마크다운 에디터 및 본문에 삽입된 사진·도면 하단에 원본 파일명이 11px 고정폭 글꼴로 중앙 정렬되어 은은하게 표시됩니다. 긴 파일명은 말줄임표(...)로 처리되며 마우스 호버 시 전체 파일명을 확인할 수 있습니다.
- **SVG 도면 렌더링 정상화**: 상대 크기(`width="100%"`) SVG 다이어그램이 브라우저에서 0x0으로 축소되는 현상을 방지하여, 본문 전체 너비에 맞추어 선명하고 비율에 맞게 렌더링되도록 개선했습니다.
- **문서 폭 조절 및 목차(TOC) 위치 정렬**: 문서 가로 폭 조절 손잡이와 우측 목차 패널 간격을 최적화하여 겹침 없이 편리하게 탐색할 수 있도록 UI를 다듬었습니다.
- **터미널 및 에디터 안정화**: 터미널 출력 및 에디터 내부 상태 동기화 안정성을 향상했습니다.

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 21 런타임 동봉: Java 별도 설치 불필요
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.0.2_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다.
3. Applications에서 앱을 실행합니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

## 하지 못한 것과 알려진 문제

- **편집기 점검이 첫 실행에서 한 번 실패했다.** `native-roundtrip-B2`(이스케이프한 Markdown 기호를 고쳐 쓰는 사례)가 `timeout: save B2`로 끝났다. 남은 진단을 보면 앱이 그 노트에 저장(`update-doc`)을 시도하지 않았고, 시험은 20초 동안 노트를 읽기만 했다. 같은 코드로 편집기 점검을 두 번 더 돌렸을 때는 모두 116건이 통과했다. 원인은 확인하지 못했다. 0.0.5 때 `views`의 「새 창으로 이동」 점검이 한 번 시간 초과로 실패했다가 다시 돌려 통과한 일과 같은 모양이지만, 같은 원인인지는 모른다. 이번 변경 때문인지, 이전 버전에도 있던 간헐 실패인지 가르는 비교(0.0.5 코드로 반복 실행)는 하지 않았다.
- 깨끗한 Mac에서 Finder로 설치해 본 확인, Java가 없는 Mac에서 설치해 본 확인은 없다.
- Apple 공증은 받지 않았다.
- 이번에 더한 AI 출처 아이콘과 코드 블록 문법 색은 실제 앱 창에서 눈으로 확인하지 못했다. 아이콘은 화면 시험(Node)으로, 문법 색은 번들 빌드와 같은 구성의 화면을 브라우저에서 띄워 확인했고, 실제 창 점검 10종은 이 둘을 따로 재지 않는다.
- 0.0.5에서 더한 화면(「스킬·에이전트」, 프로젝트 페이지)도 실제 앱 창에서 손으로 눌러 본 확인이 없다.
- GitHub App으로 비공개 저장소를 받아 오는 것은 확인하지 못했다(공개 저장소만 확인).
- 승인 흐름이 없다. 스킬·에이전트의 권한 값은 저장만 하고 쓰이지 않으며, AI가 쓴 변경은 승인 없이 바로 적용된다([이슈 #53](https://github.com/bnjjong/aisurada/issues/53)).

# aisurada 0.0.6 — 노트 목록의 AI 출처 아이콘, 코드 블록 문법 색

Apple Silicon Mac용 `0.0.6` 배포입니다. **설치 파일은 Assets의 `aisurada_0.0.6_aarch64.dmg`입니다.**

0.0.5 이후 화면에 더한 두 가지를 묶은 작은 배포입니다. 목록에서 노트를 어느 AI로 만들었는지 바로 알아볼 수 있고, 코드 블록에 언어별 색이 입혀집니다. 엔진과 데이터 형식은 바뀐 것이 없습니다.

## 주요 변경 사항

- **전체 노트와 캘린더 목록에 AI 출처 아이콘이 붙습니다.**
  - 노트 머리말에 세션 정보가 있으면 그 노트를 만든 CLI(Claude Code, Codex, Gemini CLI)의 아이콘이 목록 줄에 나옵니다. 다른 CLI로 고쳤다면 고친 쪽 아이콘이 이어서 나옵니다. 같은 CLI로 만들고 고쳤으면 아이콘 하나만 나옵니다.
  - 전체 노트 목록, 캘린더의 아젠다 목록, 주 보기의 목록 모드 칩에 붙습니다. 칩에서는 글자가 잘려도 아이콘이 가려지지 않도록 글자 앞에 둡니다. 세션 정보가 없는 노트에는 아이콘이 없습니다.
- **코드 블록에 문법 색이 입혀집니다.** 지금까지는 어떤 언어든 한 가지 색(검정)으로만 보였습니다.
  - 편집기, 읽기 화면, Claude 대화 패널의 코드 블록이 같은 색 규칙을 씁니다. 밝은 테마, 어두운 테마, OS 설정 따라가기 모두에 맞춘 색이 있습니다.
  - Kotlin, Groovy(Gradle), Bash(zsh), YAML, JSON, Dockerfile, properties, TOML, JSX, TSX를 새로 더했습니다. 편집기의 언어 선택 목록에는 있었지만 색이 입혀지지 않던 언어입니다.
  - 언어를 적지 않은 코드 블록은 색을 입히지 않고 그대로 둡니다. 편집기가 언어를 멋대로 정해 저장 때 Markdown 펜스를 바꾸는 일을 막기 위해서입니다.

## 알려진 문제

- **새로 더한 아이콘과 문법 색은 실제 앱 창에서 손으로 눌러 본 확인이 없습니다.** 문법 색은 번들 빌드와 같은 구성의 화면을 브라우저에서 띄워 코드 블록의 색 입히기를 확인했고, 아이콘은 화면 시험으로 확인했습니다.
- **스킬·에이전트의 권한 값은 아직 쓰이지 않습니다.** 읽기·수정·공개 권한을 저장하지만 어디에도 적용하지 않습니다. AI가 쓴 변경(참조와 권한 포함)은 승인 없이 바로 적용되고, 이력으로만 되돌릴 수 있습니다. 승인 흐름은 [이슈 #53](https://github.com/bnjjong/aisurada/issues/53)에서 이어 갑니다.
- 프로젝트를 지워도 그 프로젝트의 스킬·에이전트 폴더(`.aisurada/resources/projects/<프로젝트>`)는 남습니다.
- GitHub App 연결은 공개 저장소로만 확인했습니다. 비공개 저장소를 받아 오는 것은 확인하지 못했습니다.
- Antigravity 대화는 시스템의 `sqlite3`(macOS 기본)로 읽습니다. Antigravity가 내용을 비워 둔 오래된 단계는 보이지 않고, 도구 결과는 보이지 않습니다. 세션 칩에는 Gemini CLI와 같은 「Gemini CLI」로 나옵니다.
- 세션 목록 화면에는 Codex·Gemini 세션이 나오지 않고, 노트 칩으로 들어간 세션 화면은 읽기 전용입니다.
- 0.0.5에서 더한 화면(「스킬·에이전트」, 프로젝트 페이지)도 실제 앱 창에서 손으로 눌러 본 확인이 없습니다. 모의 엔진을 쓰는 화면 시험과 엔진·호스트 시험으로만 확인했습니다.
- 0.0.4 이하 버전이 0.0.5 이후 버전에서 만든 노트를 다시 쓰면 머리말의 `sessionAgent`, `editedSessionAgent` 줄이 지워질 수 있습니다.

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 21 런타임 동봉: Java 별도 설치 불필요
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.0.6_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다. 이전 버전이 있으면 덮어씁니다.
3. Applications에서 앱을 실행합니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

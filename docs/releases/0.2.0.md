# aisurada 0.2.0 — 의사결정 블록과 전면 리사이즈 모달

Apple Silicon Mac용 `0.2.0` 마이너 릴리즈입니다. **설치 파일은 Assets의 `aisurada_0.2.0_aarch64.dmg`입니다.**

0.1.2 이후 AI가 사람의 판단을 요청하고 기다릴 수 있는 **의사결정 블록(Decision Blocks)** 시스템을 전면 도입하고, 앱 내 모든 모달의 **창 크기 조절(Resizable Modal)** 기본 적용, 사이드바 레일의 **프로젝트 리소스 트리 펼침**을 지원하는 메이저급 마이너 업데이트입니다.

## 주요 변경 사항

- **의사결정 블록(Decision Blocks) 시스템 전면 도입**
  - **사람의 판단을 기다리는 의사결정 블록**: AI가 작업 중 임의로 추측할 수 없는 설계 선택지나 승인이 필요할 때 노트를 작성하고 진행을 멈추는 `decide` 블록 규격을 도입했습니다. 사람이 선택을 마치면 `decided` 블록으로 기록됩니다.
  - **엔진 레벨 대기 및 파싱**: 엔진과 러너가 의사결정 블록을 감지하여 러너 작업을 대기 상태로 유지하고 사용자가 응답할 때까지 안전하게 보존합니다.
  - **편집기 전용 시각 렌더링**: 리치 편집기(Lexical) 내에서 의사결정 블록을 전용 카드 형태로 렌더링하여 선택지와 결정 상태를 한눈에 파악할 수 있습니다.
  - **대기 상태 알림 및 안내**: AI가 노트의 결정을 기다리는 중일 때 상단 바와 안내를 통해 사람에게 결정이 필요한 사항이 있음을 직관적으로 알려줍니다.
- **모든 팝업 모달 크기 조절(Resizable) 기본화**
  - 에이전트 수정, 스킬 수정, 승인 대기함뿐만 아니라 설정, 검색, 미리보기 등 앱 내 모든 팝업 모달에 8방향 리사이즈 핸들과 하단 손잡이 띠(`ui-modal-gripbar`)를 기본 적용했습니다.
  - 모달 내용이나 액션 버튼과 손잡이가 겹치지 않으며, 최소 및 최대 크기 보호가 기본 동작합니다.
- **사이드바 레일 프로젝트 리소스 펼침 지원**
  - 사이드바 레일의 프로젝트 항목 아래에서 해당 프로젝트가 사용하는 에이전트와 스킬 목록을 바로 펼쳐 보고 탐색할 수 있습니다.
- **체크리스트 클릭 영역 정렬 일치**
  - 편집기 내 체크리스트 체크박스와 실제 마우스 클릭 감지 영역의 위치를 정확히 일치시켜 클릭 오동작을 해결했습니다.
- **에이전트 목록 모델 체인 한 줄 표시 보장**
  - 1·2·3순위 AI 모델 체인이 어떤 모델명과 추론 강도 조합에서도 줄바꿈되지 않고 한 줄로 단정하게 표시됩니다.

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 불필요 (100% Rust 네이티브 엔진)
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.2.0_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다. 이전 버전이 있으면 덮어씁니다.
3. Applications에서 앱을 실행합니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

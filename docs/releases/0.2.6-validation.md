  - 저장된 인테이크 질문 전달 및 알림 통합 (`TSK-20`).
- **입력 유효성 검증 (PR #169)**

  - `TypedHostCall`에 판별 유니온 튜플을 도입하여 `<T>` 결과 타입을 명시한 호출에서도 인자 검사를 강제하도록 보강.
  - `notifications_mark_read`의 `ids: string[] | null` Rust Option 시그니처 1:1 일치.
  - 412/409 및 태스크 상태 충돌 분기 단위 시험 보강.
  - 골든 bless 도구 전체 로그 출력 개선.
  - 개발자 가이드 시험 수치 최신화 (엔진 358건, Node 702건).

## 로컬 릴리즈 빌드 및 번들 검증

`AISURADA_RELEASE_TAG=v0.2.6 pnpm --dir native-host release:build` 명령으로 검증 및 패키징을 수행했습니다. 번들 빌드와 번들 검증 10항목이 모두 통과했습니다.

- **번들 검증 10항목:**
  1. 앱에 `ais-cli`·라이선스·사용자 안내서가 든다
  2. Java 런타임과 JAR이 없다
  3. 번들 버전이 0.2.6이다
  4. ARM64 앱과 `ais-cli`와 안쪽 코드의 서명 검증
  5. 번들 `ais-cli`가 한글·공백 경로에 작업 공간을 만든다
  6. PATH에 아무것도 없이 번들 CLI가 노트를 만들고 따로 뜬 프로세스가 읽는다
  7. Claude MCP 등록이 번들 `ais-cli`를 가리킨다
  8. 번들 `ais-cli`가 표준 입출력 MCP를 서비스한다(`initialize`, `tools/list`, `tools/call`)
  9. DMG를 꺼낸 뒤에도 복사한 앱의 엔진 검사가 통한다
  10. 복사한 DMG 앱이 격리 HOME에서 계속 떠 있다

- **크기:**
  - DMG: 17,199,573 바이트 (약 16.40 MiB)
  - 앱 번들: 36,672 KiB
  - 동봉 CLI (`ais-cli`): 5,548 KiB

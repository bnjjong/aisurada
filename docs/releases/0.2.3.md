# aisurada 0.2.3 — 스위치 손잡이 격리 및 스킨별 형태 보존 패치

Apple Silicon Mac용 `0.2.3` 패치 배포입니다. **설치 파일은 Assets의 `aisurada_0.2.3_aarch64.dmg`입니다.**

0.2.2 이후 **토글 스위치(SettingsSwitch)의 체크박스 스타일 누수 해결** 및 **스킨별 손잡이 고유 형태 보존**을 포함하는 패치 업데이트입니다.

## 주요 변경 사항

- **토글 스위치 손잡이 크기 격리 및 형태 왜곡 결함 수정**
  - **체크박스 스타일 누수 차단**: `<input type="checkbox" role="switch">` 기반 스위치(`.set-toggle`)가 켜졌을 때 일반 체크박스의 체크마크 가상요소 크기(`9px × 5px`)가 상속되어 손잡이가 납작한 타원형으로 찌그러지던 결함을 수정했습니다.
  - **스킨별 고유 손잡이 형태 및 크기 보존**:
    - **격자(grid) 스킨**: 14×14px 각진 네모 손잡이(`border-radius: 1px`)가 켜졌을 때도 원형으로 바뀌거나 삐져나오지 않고 완벽히 유지됩니다.
    - **모던(modern) 스킨**: 14×14px 흰색 원형 손잡이가 켜짐/꺼짐 시 일관된 크기와 이동 위치를 유지합니다.
    - **택타일(tactile) / 글래스(glass) 스킨**: 20×20px 원형 손잡이 규격을 고정했습니다.
    - **기본/클래식(classic) 스킨**: 18×18px 원형 손잡이와 WCAG 3:1 대비 테두리를 유지합니다.
  - **스위치-체크박스 격리 회귀 테스트 추가**: 각 스킨의 CSS에서 스위치가 체크마크 규칙으로부터 안전하게 격리되어 있는지 자동 검증하는 테스트를 추가했습니다.

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 불필요 (100% Rust 네이티브 엔진)
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.2.3_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다. 이전 버전이 있으면 덮어씁니다.
3. Applications에서 앱을 실행합니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

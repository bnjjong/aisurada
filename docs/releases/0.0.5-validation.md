## 시험 정비

0.0.4 이후 화면을 바꾸면서 실제 창 점검을 돌리지 않았고, 이번에 처음 돌렸을 때 `views`의 두 곳이 붉었다. 제품 코드는 건드리지 않고 시험의 기대값만 현재 동작에 맞췄다(`4dca9e1`).

- 레일 메뉴 점검: 「스킬·에이전트」 메뉴가 더해져 7개가 아니라 8개다. 점검 이름도 `rail-eight-order-…`로 바꿨다.
- 새 프로젝트·새 아젠다 점검: 레일의 「프로젝트 추가」와 「아젠다 추가」 단추가 「새로 만들기」 메뉴 하나로 합쳐졌다. 메뉴를 열어 항목을 고르도록 고쳤다.

## 하지 못한 것과 알려진 문제

- 깨끗한 Mac에서 Finder로 설치해 본 확인, Java가 없는 Mac에서 설치해 본 확인은 없다.
- Apple 공증은 받지 않았다.
- 이번에 더한 화면(「스킬·에이전트」, 프로젝트 페이지)은 실제 창 점검이 다루지 않는다. 모의 엔진을 쓰는 화면 시험과 엔진 시험으로만 확인했고, 실제 앱 창에서 손으로 눌러 본 확인은 없다.
- Antigravity 대화를 노트 칩의 「터미널」로 `agy --conversation`으로 이어 여는 것은 호스트 단위 시험과 화면 시험으로만 확인했다. 실제 앱 창에서 눌러 보고 대화가 열리는 것까지는 확인하지 못했다. Antigravity 기록 읽기는 실제 기록으로 읽기 전용으로 확인했다.
- GitHub App으로 비공개 저장소를 받아 오는 것은 확인하지 못했다(공개 저장소만 확인).
- 전체 시험을 처음 돌릴 때 `views`의 「새 창으로 이동」 점검이 한 번 시간 초과(`moved note window`)로 실패했다. 같은 코드로 다시 돌렸을 때는 통과했고, 원인은 확인하지 못했다.
- 승인 흐름이 없다. 스킬·에이전트의 권한 값은 저장만 하고 쓰이지 않으며, AI가 쓴 변경은 승인 없이 바로 적용된다([이슈 #53](https://github.com/bnjjong/aisurada/issues/53)).

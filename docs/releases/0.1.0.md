# aisurada 0.1.0 — 3단계 AI 엔진 폴백 체인과 크기 조절 모달, 정식 릴리즈

Apple Silicon Mac용 `0.1.0` 정식 배포입니다. **설치 파일은 Assets의 `aisurada_0.1.0_aarch64.dmg`입니다.**

0.0.9 이후 3단계 AI 엔진 폴백 체인(1순위 기본, 2순위 토큰 고갈 대비 필수 폴백, 3순위 선택 폴백)과 2026 최신 공식 모델 라인업 및 모델별 추론 강도(Reasoning Effort) 지원을 도입했습니다. 또한 크기 조절 가능한 모달(Resizable Modal), 일관된 닫기(×) 아이콘, 글래스 헤더 비침 현상 해결, 글로벌 리소스 디스크 영속성, 최근 실행 목록 레일 및 승인 체계 연동을 구축하여 정식 릴리즈(0.1.0)로 완성했습니다.

## 주요 변경 사항

- **3단계 계층형 AI 실행 엔진 및 폴백 체인 구축**
  - **1순위 기본 실행 엔진**: Gemini, Claude, Codex 중 주력 엔진과 모델, 추론 강도를 지정합니다.
  - **2순위 필수 폴백(대체) 엔진**: 1순위 엔진의 토큰이 소진되거나 장애 발생 시 즉시 투입되는 필수 대체 엔진을 지정합니다. 동일 공급자의 동시 토큰 고갈을 방지하기 위해 1순위와 동일한 공급자는 선택할 수 없습니다.
  - **3순위 선택 대체 엔진**: 필요 시 체크박스를 통해 3순위 최종 대체 모델까지 설정할 수 있습니다.
  - 사용자의 실제 환경에서 인증되어 사용 가능한 모델만 선택지에 노출되며, 복잡한 엔진 설정을 깔끔하게 접고 펼칠 수 있는 토글 기능을 추가했습니다.
- **2026 최신 공식 AI 모델 라인업 및 모델별 추론 강도(Reasoning Effort) 지원**
  - `Gemini 3.8 Flash`, `gemini-2.5-pro`, `Sonnet 5.5` 등 2026 최신 검증 모델을 탑재했습니다.
  - 모델별 특성에 맞춰 지원되는 추론 강도(`default`, `low`, `medium`, `high`, `xhigh`)만 선택할 수 있도록 연동했습니다.
- **크기 조절 가능한 모달(Resizable Modal) 및 닫기 버튼 표준화**
  - 에이전트 수정, 스킬 수정, 승인 등 주요 팝업 모달의 8방향 리사이즈 핸들을 제공하여 창 크기를 자유롭게 조절할 수 있도록 개선했습니다 (최소/최대 크기 제한 보호).
  - 모달 상단의 텍스트형 '닫기' 버튼을 표준 창 닫기(×) 아이콘으로 일원화하여 UI 일관성을 확보했습니다.
- **글래스 모달 헤더 불투명 배경 적용 (스크롤 비침 결함 해결)**
  - 글래스 테마에서 모달 스크롤 시 sticky 헤더 뒤로 폼 레이블과 본문 텍스트가 비쳐 보이던 합성(compositing) 결함을 불투명 단색 배경(`--glass-modal-header`) 적용으로 완전히 해결했습니다.
- **글로벌 리소스 디스크 영속성 및 인라인 편집**
  - 공통 개발 프로세스 에이전트, 글로벌 스킬, 리소스를 디스크(`~/.aisurada/resources.json`)에 안전하게 영속화하고 MCP 서버와 실시간 동기화합니다.
  - 유효하지 않은 스킬 자동 정리 및 수정 토큰 관리로 충돌 없는 안전한 저장을 보장합니다.
  - 에이전트 카드 및 리소스 카드 클릭 시 바로 수정 모달이 열리도록 UX를 개선했습니다.
- **사이드바 레일 개편 및 최근 실행 목록(Recent Runs) 추가**
  - 사이드바 레일 탭 순서를 최적화하고, 백그라운드 태스크 및 최근 실행 현황을 모니터링할 수 있는 최근 실행 목록 레일을 신설했습니다.
- **승인(Approvals) 체계 전면 연동 및 실시간 알림**
  - 에이전트 작업 중 사용자 승인이 필요한 순간을 감지하고, 컴패니언 헤더 및 승인 대기함 모달을 통해 즉시 확인·승인할 수 있는 통합 진입점을 구축했습니다.
- **태스크 관리 기능 고도화**
  - 태스크 상세 화면에서 제목, 설명, 완료 기준을 클릭하여 바로 수정할 수 있는 인라인 편집 기능을 추가했습니다.
  - 신규 태스크 등록을 위한 `create_task` MCP 도구를 추가하고 전체 엔진 골든 호환성을 검증했습니다.
- **Antigravity / Gemini 환경 세션 감지 및 터미널 통합**
  - Antigravity 및 Gemini 환경 세션을 정확히 식별하여 대화 이력을 안전하게 연동하도록 지원합니다.

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상
- Java 불필요 (100% Rust 네이티브 엔진)
- Intel Mac, Windows, Linux는 본 배포에서 지원하지 않습니다.

## 설치 방법

1. Assets에서 `aisurada_0.1.0_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 `Applications` 폴더로 드래그하여 복사합니다. 이전 버전이 있으면 덮어씁니다.
3. Applications에서 앱을 실행합니다.

> [!NOTE]
> 본 배포판은 ad-hoc 코드 서명이 적용되어 있습니다. 처음 실행 시 macOS 보안 경고가 나타날 경우 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 진행해 주시기 바랍니다.

## 파일 검증

배포 파일의 체크섬은 `SHA256SUMS` 및 `validation.json`에서 확인할 수 있습니다.

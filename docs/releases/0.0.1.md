# aisurada 0.0.1 — 첫 시험판

Apple Silicon Mac용 초기 시험 배포입니다. **설치 파일은 Assets의 `aisurada_0.0.1_aarch64.dmg`입니다.**

## 지원 환경

- Apple Silicon Mac (M1 이상), macOS 13 이상으로 빌드
- 로컬 검증 환경: Apple Silicon / macOS 26.6.2
- Java 21 런타임 포함: Java 별도 설치·환경변수 설정 불필요
- Intel Mac, Windows, Linux는 이 시험판에서 지원하지 않습니다.

## 설치

1. Assets에서 `aisurada_0.0.1_aarch64.dmg`를 내려받습니다.
2. DMG를 열고 `aisurada.app`을 Applications 폴더로 옮깁니다.
3. DMG를 추출한 뒤 Applications에서 앱을 실행합니다.
4. 워크스페이스를 만들거나 열고 노트를 작성합니다.

이 시험판은 **ad-hoc 서명**이며 Apple Developer ID 서명·공증을 받지 않았습니다. macOS에서 실행을 차단할 수 있습니다. 내려받은 파일의 출처와 체크섬을 확인한 뒤, 시스템 설정 → 개인정보 보호 및 보안에서 차단된 앱의 실행 허용을 진행할 수 있습니다. 조직에서 관리하는 Mac의 정책에 따라 허용되지 않을 수도 있습니다.

## 포함한 것

- Tauri 데스크톱 앱과 React 화면
- Java 엔진·CLI JAR
- Eclipse Temurin JRE 21.0.13+9 (Apple Silicon), 라이선스·고지 파일
- 앱 내부 `Contents/Resources/user-guide.html` 및 별도 HTML 사용자 가이드

## 기능별 준비 사항

- 기본 노트 작성·저장은 앱과 동봉 Java로 동작하도록 구성했습니다.
- Git 이력·자동 커밋 기능에는 별도 Git 실행 환경과 Git 저장소 설정이 필요합니다. Git은 동봉하지 않았습니다.
- Claude 기능은 별도 Claude CLI 설치와 로그인이 필요합니다. Claude CLI와 계정은 포함하지 않습니다.
- 공개 시험판은 개인 비밀 이름 분류표를 포함하지 않는 견본 빌드입니다. 터미널 출력의 비밀 가림·기록 굳히기는 분류표 상태에 따라 제한될 수 있습니다.

## 검증과 제한

- 기존 엔진·프런트엔드·Rust 검사 실행
- 최종 앱의 버전·ARM64 아키텍처·내부 리소스·코드 서명 검사
- 동봉 Java로 별도 엔진 프로세스와 CLI를 실행하여 한글·공백 경로에서 워크스페이스 생성, 노트 저장·조회, 엔진 재시작 후 내용 유지 확인
- DMG 무결성 검사, DMG에서 임시 Applications 폴더로 복사·추출한 뒤 동일한 번들 검사 및 격리된 HOME의 앱 프로세스 시작 확인
- 상세 자동 검사 결과는 `validation.json`, 배포 파일 체크섬은 `SHA256SUMS`에 제공합니다.

개발 도구가 전혀 없는 별도 Mac에서의 수동 설치, macOS 13을 포함한 모든 지원 버전, 기존 설치본에서의 업데이트는 아직 검증 범위에 포함하지 않습니다. 초기 시험판이므로 실제 데이터를 사용하기 전에 숨김 폴더·첨부를 포함한 워크스페이스 전체를 백업해 주세요.

## 업데이트와 제보

자동 업데이트는 제공하지 않습니다. 앱을 종료하고 새 버전의 DMG로 앱을 교체하는 방식입니다. 문제가 있으면 저장소 Issues에 Mac 종류·macOS 버전·앱 버전·재현 순서를 남겨 주세요. 개인 노트·인증 정보는 첨부하지 않아도 됩니다.

## Java 소스·라이선스

동봉 Java의 라이선스·NOTICE는 앱 내부 `Contents/Resources/runtime/legal/`와 `NOTICE`에 있습니다. 해당 버전의 소스는 Assets의 `OpenJDK21U-jdk-sources_21.0.13_9.tar.gz` 또는 [Eclipse Temurin 원본 배포](https://github.com/adoptium/temurin21-binaries/releases/tag/jdk-21.0.13%2B9)에서 받을 수 있습니다. Java 소스 압축 파일은 앱을 설치할 때 내려받을 필요가 없습니다.

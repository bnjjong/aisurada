# 2부 10장 완료 — wlframe 프로토콜

작성일: 2026-10-31

제공 PDF 43~47쪽대로 기존 404 자리표를 실제 비동기 파일 응답으로 바꿨다. 현재 vault를 복사해 일꾼에서 엄격한 퍼센트·UTF-8 해독과 실재 경로 검사를 한다. vault 안 notes/ 아래 attach 마디를 포함한 파일만 읽으며 13개 확장자와 32 MiB 상한을 적용한다.

성공과 거절 모두 고정 CSP, X-Content-Type-Options: nosniff, Cache-Control: no-store를 단다. 거절은 상태 코드와 빈 본문이고 Content-Type·CORS 머리를 싣지 않는다. HTML은 바이트를 보존하면서 마지막 대소문자 무관 `</body>` 앞에 높이·링크 알림 스크립트를 넣고, 닫는 줄이 없으면 뒤에 붙인다.

Rust 검사에서 상태별 순서, 깨진 퍼센트·UTF-8, 형식·크기, 심볼릭 링크 탈출, 임의 HTML 바이트 보존과 삽입 위치를 확인했다. 실제 WKWebView에서 attach의 321픽셀 문서가 높이를 알리고 첨부 밖 문서는 알리지 않는 점검이 통과했다. sandbox 부모의 높이 제한·사용자 입력 판정·외부 링크 열기는 3부에서 연결한다.

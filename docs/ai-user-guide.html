CHAPTER 01

AI에게 묻기란?

글을 복사해 나가지 않고, 노트의 맥락을 살려 그 자리에서 답을 얻는 새로운 방식입니다.

일반적인 AI 도구는 웹 브라우저나 별도 챗봇 창을 열고, 배경 설명과 함께 질문할 텍스트를 일일이 복사해서 붙여넣어야 했습니다. 질문이 끝나도 답변은 챗봇 대화 기록에 흩어져 노트 본문과 단절됩니다.

aisurada의 「AI에게 묻기」는 노트 편집 화면에서 마우스로 대목을 선택하는 즉시 실행됩니다:

💡 자동 맥락 주입

선택한 문장뿐 아니라 현재 노트의 제목, 속한 아젠다(주제), 관련 세션 기록이 함께 전송되어 군더더기 없는 정확한 답변을 도출합니다.

📂 영구 로컬 보관

답변은 외부 클라우드에만 남지 않고, 내 로컬 보관소의 해당 노트 폴더 안에 ask.json 파일로 즉시 기록되어 오프라인에서도 보존됩니다.

💬 본문 곁의 호버 카드

답변이 완료된 대목 아래에는 노란색 점선 밑줄이 생깁니다. 마우스를 올리기만 하면 카드 형태로 답을 읽고 추가 질문을 이어갈 수 있습니다.

▲ aisurada AI 문답 파이프라인: 글 드래그부터 로컬 ask.json 저장 및 호버 카드 생성까지

CHAPTER 02

시작 전 필수 준비 (최초 1회 설정)

aisurada는 사용자 머신에 설치된 공식 Claude Code CLI를 통해 안전하게 모델과 통신합니다.

⚠️ 사용 전 확인 필요

AI 문답 기능을 사용하려면 Mac 터미널에서 Claude CLI 도구가 사전에 설치되어 있고, 최초 1회 브라우저 로그인이 완료되어 있어야 합니다.

  1. Claude Code CLI 설치하기

    Mac의 터미널(Terminal) 앱을 열고 아래 공식 설치 명령어를 입력합니다:

    터미널 설치 명령어
    npm install -g @anthropic-ai/claude-code

    정상 설치 여부를 확인하려면 claude --version을 실행하세요.

  2. 터미널에서 최초 1회 로그인 완료하기

    터미널에 다음 명령어를 입력해 대화 세션을 시작합니다:

    터미널 로그인 명령어
    claude

    명령어를 실행하면 웹 브라우저가 자동으로 열립니다. Anthropic 계정으로 로그인하고 사용 권한을 승인합니다. 터미널에 프롬프트가 뜨면 정상 로그인된 것이며, Ctrl + C로 종료하셔도 됩니다.

  3. 실행 파일 경로 확인

    aisurada 앱은 실행 시 다음 표준 경로에서 claude 실행 파일을 순서대로 자동 감지합니다:

    • ~/.local/bin/claude (기본 위치)
    • /opt/homebrew/bin/claude (Apple Silicon Mac Homebrew)
    • /usr/local/bin/claude (Intel Mac Homebrew)
    • 시스템 PATH 환경변수

    특수 경로에 설치하신 경우에만 ~/.zshrc에 export AISURADA_CLAUDE_BIN="경로"를 추가해 주시면 됩니다.

  4. (선택) Google Gemini CLI 도구 준비하기

    Claude 외에 gemini 3.8 flash 모델을 함께 사용하시려면 공식 Gemini CLI를 터미널에 설치합니다:

    Gemini CLI 설치 명령어
    npm install -g @google/gemini-cli

    터미널에 export GEMINI_API_KEY="나의-API-키"가 등록되어 있으면 별도 로그인 없이 즉시 동작합니다. 특수 경로에 설치된 경우 export AISURADA_GEMINI_BIN="경로"로 지정할 수 있습니다.

CHAPTER 03

환경 설정과 모델 추천

앱 우측 상단 [⚙ 설정]에서 나에게 맞는 모델과 대기 시간을 조절하세요.

설정 항목 권장값 설명
기본 AI 모델 sonnet 5.5 또는 gemini 3.8 high
  • Claude 계열: sonnet 5.5, opus 5.5 (코드 분석, 문서 요약, 논리적 질의에서 최고 품질 제공)
  • Gemini 계열: gemini 3.8 high, gemini 3.8 medium (Google Gemini 기반 고속 질답)
추론 강도
(Thinking Effort)		 low ~ high 모델이 답변을 작성하기 전 깊게 사고(Thinking)하는 시간입니다. Claude 모델에서는 low~max를 선택할 수 있으며, gemini 3.8 high는 high로, gemini 3.8 medium은 medium으로 자동 고정(비활성화)됩니다.
문답 대기 상한
(Timeout)		 3600초 (1시간) 대규모 문서나 긴 작업 시 AI 응답을 기다리는 최대 제한 시간입니다. 기본 3600초로 설정되어 타임아웃 걱정 없이 긴 분석을 수행할 수 있습니다.
호버 카드 너비 360px 본문 밑줄에 마우스를 올렸을 때 나타나는 팝업 카드의 기본 너비입니다. 모서리를 마우스로 드래그해 자유롭게 조절할 수 있습니다.
CHAPTER 04

본문 텍스트 드래그하여 묻기

노트 작성 중 가장 빈번하게 사용하는 기본 진입 방식입니다.

  1. 본문 대목 마우스 드래그

    노트 본문에서 궁금하거나 보충 설명이 필요한 문장·단락을 마우스로 긁어 선택합니다.

  2. 도구 모음의 「AI에게 묻기」 클릭

    선택 영역 바로 위에 둥근 도구 모음([ B ] [ I ] [ S ] [ 코멘트 ] [ AI에게 묻기 ])이 뜹니다. 파란색 글씨의 「AI에게 묻기」를 클릭합니다.

  3. 질문 작성 및 그림 첨부

    선택 글자 바로 아래에 깔끔한 질문 입력 상자가 열립니다:

    • 질문 입력: 물어볼 내용을 타이핑합니다.
    • 그림 첨부 (⌘+V): 캡처한 이미지나 그림을 클립보드에 복사한 뒤 입력창에서 ⌘ + V를 누르면 이미지가 즉시 함께 첨부됩니다.
    • 옵션 변경: 상단 드롭다운을 통해 이번 질문에만 사용할 모델과 추론 강도를 일회성으로 바꿀 수 있습니다.
  4. 전송하기

    ⌘ + Enter 단축키 또는 하단의 [묻기] 버튼을 누르면 질문이 백그라운드로 전송됩니다.

CHAPTER 05

표(Table)의 특정 행(줄) 묻기

표 데이터 전체를 일일이 긁지 않고, 원하는 행만 단추 하나로 인용해 묻습니다.

데이터 표를 정리하다가 특정 줄의 수치나 내용에 대해 AI의 검토가 필요할 때 사용합니다:

  1. 표의 특정 행에 마우스 올리기

    표 안의 특정 행(Row)에 마우스를 올리면, 해당 줄 맨 왼쪽 가장자리에 점 6개 모양의 줄 손잡이와 AI 단추가 나타납니다.

  2. 「이 줄을 AI에게 묻기」 선택

    줄 손잡이를 누르면 열리는 팝업 메뉴에서 「이 줄을 AI에게 묻기」를 누르거나, 줄 옆의 파란색 AI 단추를 바로 클릭합니다.

  3. 자동 캡처 및 질문

    그 행에 속한 모든 칸(Cell)의 텍스트가 탭으로 구분된 인용문으로 자동 묶여 질문 상자에 담깁니다. 질문을 적고 ⌘ + Enter로 전송하세요.

CHAPTER 06

답변 확인 및 이어 묻기 (Follow-up)

답변은 본문에 밑줄로 남고, 마우스를 올리면 카드가 열려 대화를 이어갑니다.

🟡 노란색 점선 밑줄

질문한 대목 아래에 노란색 점선 밑줄이 심어집니다. 본문 문맥을 훼손하지 않으면서 어떤 부분에 질문을 남겼는지 한눈에 알 수 있습니다.

🪟 마우스 올림 카드 (Hover Card)

노란 밑줄 위에 마우스를 올리면 팝업 카드가 부드럽게 나타납니다. AI가 작성한 상세 답변과 질문 시각, 모델 정보를 바로 읽을 수 있습니다.

🔄 이 대목에 이어 묻기

카드 아래의 「이 대목에 이어 묻기」 단추를 누르면, 이전 질문과 답변의 문맥을 그대로 유지한 채 추가 질의(멀티턴 대화)를 지속할 수 있습니다.

노트 맨 아래 「AI 문답」 종합 패널

노트 하단으로 스크롤을 내리면 해당 노트에서 주고받은 모든 질문과 답변을 한자리에서 시간순으로 펼쳐볼 수 있는 전용 패널이 마련되어 있습니다.

CHAPTER 07

자주 묻는 문제 해결 (FAQ)

기능이 예상대로 동작하지 않을 때 먼저 점검할 4가지 항목입니다.

Q1. 글을 드래그해도 'AI에게 묻기' 단추가 보이지 않아요.

• 샘플 워크스페이스 여부: 앱 사이드바 상단에 샘플 배지가 붙어 있다면 임시 체험 모드입니다. 샘플 상태에서는 파일 수정과 AI 전송이 차단되므로, 사이드바 하단 [시작 화면]에서 실제 로컬 폴더(Vault)를 열어주세요.

• 보관소 경로 확인: 사이드바 상단 워크스페이스 이름 아래에 /Users/... 형태의 실제 폴더 경로가 정상 출력되고 있는지 확인하세요.

• 미리보기 뷰가 아닌지 확인: 캘린더나 검색에서 뜬 '미리보기 팝업'은 읽기 전용입니다. 노트를 편집 탭으로 열어 본문에서 드래그하세요.

Q2. 질문 전송 후 빨간색 실패 카드가 떠요.

• 터미널에서 claude를 입력해 로그인이 유지되고 있는지 확인하세요. 브라우저 인증 세션이 만료되면 API 호출이 거절됩니다.

• 계정의 사용량 한도(Rate limit)나 잔여 크레딧 상태를 확인하세요.

Q3. 질문을 보냈는데 회전 표시(대기)에서 안 넘어가요.

• 동일한 노트에 이전 질문이 아직 응답을 생성하고 있다면, 새로 보낸 질문은 순차 큐(FIFO: 선착순 대기줄)에 들어가 대기합니다. 앞 질문이 끝나면 즉시 시작됩니다.

Q4. 질문 팝업창이 엉뚱한 곳에 뜨지 않나요?

• 최신 업데이트(PR #11)를 통해 팝업창이 선택 글자 바로 아래에 정확히 뜨며, 화면 오른쪽 끝에서도 창 밖으로 잘리지 않도록 안전 클램프가 적용되었습니다.

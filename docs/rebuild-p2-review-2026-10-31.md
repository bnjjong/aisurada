# 2부 외부 검증 피드백 확인

작성일: 2026-10-31

사용자가 제공한 IMG_7903.HEIC부터 IMG_7907.HEIC까지 다섯 사진의 검증 기록을 읽고 현재 코드와 대조했다. 검증 대상은 2부 9~18장 구현 커밋 `fb64a5a`다. 사진에 기록된 외부 실행 결과와 이번 코드 대조를 구분해 적는다.

## 사진에 기록된 외부 검증 결과

- 원본 받아들임 검사 26개가 모두 통과했고, 기존 호스트 대조군도 26개가 통과했다.
- 2부 커맨드 29개가 등록됐고 이름이 기존 호스트와 같았다.
- 다시 만든 1부와 2부를 함께 붙인 합치기 1~3단계가 통과했다. 기존 3부 화면의 14개 걸음과 편집한 글의 note.md 저장도 확인했다.
- get-doc와 get-ask의 종료 코드 3은 없는 노트와 4부 없음에 대한 의도한 거절이었다.
- 메뉴 배선, 환경 정리, wlframe의 CSP·크기·형식, 창 배치 수치, PTY 유예·버퍼와 C51의 인스턴스 검사는 코드 읽기로 기존 구현·설명서와 맞췄다.

이 결과는 제공된 사진의 보고 내용을 확인한 것이다. 이번 회차에 원본 검사나 합치기를 새로 실행하지는 않았다. 기존 3부를 붙인 별도 환경의 검증이며, 이 저장소의 최소 호스트 화면을 실제 편집 화면으로 교체한 것은 아니다.

## 확인된 동작 차이 네 가지

| 항목 | 현재 코드에서 확인한 동작 | 후속 판단 |
|---|---|---|
| 없는 `a/.` 폴더 생성 | 검사한 경로 마디로 폴더를 만들고 받은 경로 표기는 응답에 보존한다. 기존 호스트와 결과가 다르다. | 현 동작 유지 권고. 이름 정규화와 응답 표기를 명세에 함께 적는다. |
| 출력을 먼저 닫은 자식 | stdout·stderr의 EOF 뒤에도 자식 종료를 기다리며 시간 제한을 적용한다. | 현 시간 제한 유지 권고. 출력 종료와 프로세스 종료의 차이를 명세에 적는다. |
| 이름이 정확히 `.app`인 폴더 | 파일 이름 끝을 검사해 기본 앱 열기를 거절한다. | 현 거절 유지 권고. `.app` 자체와 `Some.app`을 모두 명시한다. |
| 개발용 jar 후보 | 작업 폴더 위 세 단계 안에서 build.sh와 src/withlog가 있는 저장소의 dist/<모듈>.jar를 추가로 찾는다. | 이 저장소의 빌드 구조에 맞춘 예외로 유지 권고. 원본 후보와 우선순위를 구분해 명시한다. |

확인한 코드는 [폴더 생성](../native-host/src-tauri/src/workspace.rs), [프로세스 실행](../native-host/src-tauri/src/process.rs), [기본 앱 열기](../native-host/src-tauri/src/files.rs), [jar 탐색](../native-host/src-tauri/src/sidecar.rs)다. 앞의 두 차이와 jar 예외는 기존 완료 문서에도 동작을 적었지만, 원본 대비 차이 네 건을 모아 확정하는 기록이 부족했다.

위 표는 유지 권고이며 명세상의 최종 결정으로 표시하지 않는다. 이번 커밋은 피드백 기록과 문서 연결만 추가하며 실행 동작은 바꾸지 않는다. 피드백이 지목한 설명서 보완 위치는 4.6의 4번, 6.3, 7.2의 5번이며 jar 후보의 닫힌 목록 여부도 정해야 한다.

## 앱을 직접 조작해 확인할 항목

여기서 손 확인은 앱을 실제로 켜고 메뉴를 누르거나 창을 옮기는 등 사용자 조작으로 검증하는 일을 뜻한다. 사진의 외부 검증에서도 아래 일곱 항목은 수행하지 않았다. 코드 대조와 자동 점검 통과를 이 항목의 완료로 세지 않는다.

- [ ] 실제 셸 설정·Keychain 환경에서 비밀 표 뜨기와 굳히기
- [ ] main·노트 창의 실제 메뉴 클릭과 받는 창
- [ ] 허용한 파일을 기본 앱으로 실제 열기
- [ ] 모니터 조합 변경과 yabai 데스크톱 복원
- [ ] 번들 앱의 withlog 스킴·Markdown 파일 연결·자원 경로
- [ ] 개발 실행의 jar 선택을 실제 앱에서 확인
- [ ] 편집 중인 노트 창의 닫기 요청·Cmd+W와 저장

현재 상태는 자동 검증과 외부 통합 검증 통과, 동작 차이 네 건의 명세 확정 및 실제 조작 검증 대기다. [18장 완료 기록](rebuild-p2-chapter18-complete.md)의 자동 검증 범위와 함께 읽는다.

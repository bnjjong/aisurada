# 3부 고치기 증분 1: 스토어와 vault 8줄

[3부 고치기 플랜](rebuild-p3-fix-plan.md)의 증분 1이다. 부록 C에서 「고친다」로 정한 8줄을 다시 지은 화면(`native-host/`)에 넣었다.

- 기준은 「3부 설명서 고친다 30줄」 플랜(2026-11-02)과 설명서 부록 C.3의 「고치면」이다.
- 기준 판은 aisurada `17f7457`이다.

고침을 하나씩 빼고 해당 시험 파일을 돌렸다. 8가지 모두 그 줄의 시험 1개만 실패했다.

## 3. 그대로 둔 것

- 하위 노트 만들기는 재조정과 겹치면 읽기가 새 하위 노트를 뺄 수 있다. C175는 노트 만들기와 휴지통 보내기만 정했다.
- 머리가 `<!--withlog`인 옛 `.html` 노트는 다른 세션의 `9cf4dde`가 읽게 고쳤다. 이 증분은 그 위로 옮기면서 머리 읽기 뒤에 백업하는 차례를 지켰고, 둘이 맞물리는 시험(「C10 with the <!--withlog head」)을 더했다.
- 원본 지우기가 실패한 옛 노트가 다음 열기에 `-2` 폴더로 겹치는 것(C54)은 「지킨다」라서 시험도 그대로 둔다.

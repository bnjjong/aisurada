현재 화면 기준: 프로젝트별 에이전트·스킬 등록 UI 개선안

사용자께서 올려주신 최신 실제 앱 화면(IntelliJ 세로 Activity Bar + Companion Card)을 1:1로 반영하여, 프로젝트 하위에 에이전트와 스킬을 직관적으로 등록할 수 있도록 설계한 비교안입니다.

💡 현재 화면에서 확인되는 핵심 구조
- 좌측 3개 세로 아이콘: [1] 문서(노트) · [2] 로봇(에이전트) · [3] 지구본(글로벌 리소스)
- 현재 문제점: 노트 화면의 📁 aisurada 프로젝트 폴더 아래에는 오직 🟢 aisurada 개발(아젠다)만 있고, 이 프로젝트 전용 에이전트와 스킬을 등록하거나 확인할 수 있는 경로가 완전히 누락되어 있습니다.

✨ 개선 핵심 3가지

  1. 트리 하위 직관성: 📁 aisurada 아래에 아젠다뿐 아니라 🤖 에이전트, ⚡️ 스킬 항목과 개수가 바로 보임.
  2. 원클릭 즉시 등록: 각 항목 옆 +등록 버튼 또는 프로젝트 헤더 + 메뉴를 누르면 해당 프로젝트 전용 등록 모달이 바로 뜸.
  3. 프로젝트 종합 페이지 이동: aisurada 프로젝트 이름을 클릭하면 프로젝트 전용 상세 관리 페이지(참조 켜기/끄기, 목록 전체 관리)로 바로 이동.

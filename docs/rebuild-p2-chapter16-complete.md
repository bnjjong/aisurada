# 2부 16장 완료 — 4부 이음매

작성일: 2026-10-31

제공 PDF 71~74쪽에서 정한 4부를 뺀 재구현 범위로 마무리했다. 2부 커맨드 29개만 등록하며 4부 커맨드 9개는 등록하지 않는다. 호출하면 Tauri의 Command … not found 거절을 받는다. Cargo --no-default-features로 호스트와 검사 페이지를 실행할 수 있다.

4부가 빌려 쓸 프로세스 상한·실행 파일 탐색·vault 환경·번들 판정·바이트 IPC·그림 검사와 크기 상한·PTY 표와 로그인 셸·출력 채널을 2부 모듈에 둔다. 2부 코드가 4부를 호출하는 길은 없다. show_in_main의 rail은 해석하지 않고 전달한다.

실제 검사 회차는 4부가 없는 Java 엔진의 WL-409도 확인하고, 호스트의 4부 커맨드 아홉 개가 모두 not found로 거절되는지도 확인한다. PATH 앞의 가짜 claude 호출 수는 0이었다.

원본 4부 소스와 wl-agent 자원은 제공되지 않았다. 원본의 기본 claude 기능과 켠 판을 재현하지 않으며, 이 호스트는 2부 전용 판이다. 4부를 붙일 때는 해당 모듈과 화면·엔진의 세 스위치를 함께 연결해야 한다. 원본 소스 글자에 매인 검사 22개도 제공되지 않아 이 저장소의 동작 검사로 대체했다.

# 12-1 구현 검토

검토일: 2026-10-28

## 결과

응답 타입과 validator, 도구·명령 표면의 호출 형식, 기존 디코더 재사용은 12-1 계획과 부합한다. 최초 검토에서 아래 테스트 보완을 요청했고, 후속 검토에서 반영된 것을 확인했다. 2026-10-28 재실행 결과 테스트 15개 파일·269개가 통과했고 `npm run build`도 성공했다. 이 검토는 mock 기반이며 실제 엔진의 검색·집계·정렬이나 공식 수용 묶음을 확인한 결과가 아니다.

## 보완 완료된 검증

1. 명세 fixture의 정확한 바이트를 독립된 기대 바이트와 비교하는 테스트가 없었다. 12.6 원문을 독립 기대값으로 두고 `rawBytes`의 내용·키 순서·들여쓰기·마지막 LF를 전체 비교하는 테스트가 추가됐다. 실제 엔진 실행 검증과 구분돼 있다.
2. `listTags` 호출에서 로컬 전송 실패가 공통 디코더를 통해 보존되는 테스트가 없었다. MockTransport로 실패를 주입하여 `transport_failure`, 원인과 복구 지침을 확인하고 WL 코드가 임의로 부여되지 않는지 검사한다.

위 두 항목에 대해 독립 기대 바이트 비교, pre_dispatch·in_flight 전송 실패 및 신호 종료 테스트가 추가됐다. 양쪽 표면의 NFC/NFD와 특수문자 원문 전달 테스트도 확인했다.

## 별도 선행 과제

8-2의 스냅숏 중첩 격리 결함과 7-1의 쓰기 결과 분류 문제는 기존에 기록된 별도 작업이다. 12-2 실제 화면·저장 연동 전 해결한다. 이번 검토에서 애플리케이션 소스는 변경하지 않았다.

# 2부 11장 완료 — main 창과 메뉴

작성일: 2026-10-31

제공 PDF 48~50쪽을 기준으로 main 창 생성에 모니터 환경의 main 칸, 마지막 자리 파일, 설정 기본값 순서를 연결했다. 좌표는 내용 영역의 논리 픽셀이다. 모니터 안의 기억한 자리는 최소 크기와 제목 줄 28픽셀을 고려해 맞추고, 모니터 밖이면 크기·자리 모두 버리고 설정 크기로 중앙에 연다. 기억한 데스크톱 복원도 창 생성 뒤 연결했다.

기존 네 서브메뉴와 파일 메뉴 다섯 이벤트를 유지한다. Cmd+W는 포커스를 가진 창 하나에, 다른 네 동작은 main에 보낸다. 노트 창에서 main 동작을 누르면 main을 앞으로 가져온다. 실제 메뉴 클릭은 자동화하지 않았다.

공유 geometry·레이아웃 Rust 검사와 실제 WKWebView 회차 뒤 main-window.dev.json 모양 점검이 통과했다. 실제 메뉴 클릭, Cmd+W의 편집 글 저장과 창 닫기는 18장 손 확인 목록으로 남는다.

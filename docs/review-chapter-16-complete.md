## 구현 내용

- [`subNotesExplorer.ts`](../src/engine/reading/subNotesExplorer.ts): vault·부모 원문·표면·본문 모드별 캐시, 초기/로딩/성공/실패·이전 성공, 요청 세대, 방문 이력과 제목, ref 이동·뒤로 가기·breadcrumb, 모드 전환·재조회·갱신 신호·dispose를 구현했다. 조상·자손 갱신은 관련 캐시의 모든 모드를 무효화하며, 첫 응답 이전의 참조 관계는 보수적으로 취급한다. 자동 재조회와 이전 본문/새 토큰 결합은 하지 않는다.
- 상태에 들어오는 결과와 구독자·조회 스냅숏의 중첩 JSON·Error·Uint8Array를 기존 복제 정책으로 분리했다. 주입 함수 예외는 reader_error이며 임의 WL 코드로 바꾸지 않는다. 늦은 성공/실패, 재진입 중 이전 요청, 폐기 후 결과를 차단한다.
- [`SubNotesPanel.tsx`](../src/components/SubNotesPanel.tsx)와 [`DocRoute.tsx`](../src/views/DocRoute.tsx): 메인 ID 입력, 보관함 선택, 직계 목록·단계별 이동·본문 미리보기, 로딩·빈 결과·실패·이전 목록·stderr 진단, 목록 다시 읽기와 명시적 색인 갱신을 연결했다. vault·전체 parent·본문 모드는 URL query로 복원한다. HTML 본문은 텍스트로 표시한다. 새로고침으로 방문 이력이 사라져도 메인 노트로 돌아갈 수 있다.
- [`httpTransport.ts`](../src/engine/httpTransport.ts)와 [`engineHost.ts`](../host/engineHost.ts): Vite 개발/preview용 로컬 HTTP→Java 단발 전송을 구현했다. 실행 파일/JAR/vault는 호스트 구성에서만 선택한다. shell을 사용하지 않고 설정 인자·NUL·미지원 명령을 차단하며 원본 stdout/stderr를 바이트로 복원한다. 자식 프로세스의 종료·신호·spawn 실패·시간/출력 상한을 구분한다.
- 브라우저 번들에 Node 실행 코드를 넣지 않았다. 프런트 및 호스트 TypeScript를 build에서 각각 검사한다. 배포용 Tauri·장기 소켓 서비스 및 정적 호스팅의 별도 API 서버는 이번 연결과 구분한다.

## 검증

- 실제 엔진 환경 변수를 지정한 전체 `npm test`: **22개 파일·558개 테스트 통과**. 이 중 6개는 명시된 재구현 JAR을 실행하는 격리 HTTP 통합 시험이다. 환경 변수가 없으면 해당 6개는 skip이다.
- `npm run build`: 프런트·호스트 타입 검사 및 Vite 빌드 통과.
- 상태 모델은 요청 역전, vault·부모·표면·본문 모드 분리, 원문/응답 참조 구분, 뒤로 가기, 빈 성공/실패, 재진입, 갱신 중 응답 무효화, 복제와 폐기를 검증했다.
- 실제 시험용 자식 프로세스로 argv/바이너리 바이트, 종료·신호·timeout·출력 제한·spawn 오류를 검증했다. HTTP 경로와 미등록 보관함·외부 origin 차단도 확인했다.
- 재구현 JAR 통합은 직계와 손자 제외, 형제 created/id 순서, 파일 SHA-256 토큰, 도장/세션·태그·옛 경로, 중첩 ref, 본문/json 예외, 빈/단일 파일/json 부모, 기록 층의 표면 차이와 사슬 우선순위, WL-400/404/409, 새 파일 즉시 반영을 확인했다.
- ego-browser에서 실제 로컬 호스트를 열어 메인→자식→손자, 빈 목록, 본문 미리보기, 새로고침 복원과 메인 복귀, 명시적 색인 갱신, 기록 층, 보관함 전환의 WL-404를 확인했다. [화면 기록](./artifact-updates/chapter16-preview-2026-10-28.png)을 남겼다.

## 검증 한계

이 결과는 **재구현 엔진**을 대상으로 한다. 원본 SQLite 엔진의 111건 공식 수용 묶음은 제공되지 않아 실행하지 않았다. 재구현은 매 호출 디스크를 훑으므로 새 파일이 바로 보인다. 원본의 색인 지연, 메타/현재 파일 혼합, 파일 삭제·UTF-8/크기/I/O 오류와 잡히지 않는 YAML·HTML 첨부 예외의 원본 전파 동작을 이 통합 시험으로 확인했다고 주장하지 않는다. 이 경계는 원본 엔진 확보 후 별도 검증이 필요하다.

하위 노트 상세·코멘트와 편집/저장은 11.8 및 쓰기 명세의 별도 기능이다. 현재 목록 본문 미리보기는 상세 읽기 계약의 대체가 아니다. 감시 서비스를 추가하지 않았으며 갱신 신호 API와 수동 갱신을 제공한다. 정적 dist 단독 배포는 엔진 실행 호스트를 포함하지 않는다.

Git 원격과 배포 대상은 엔진 검증과 별개다. 실제 커밋·푸시 결과는 작업 종료 보고를 따른다.

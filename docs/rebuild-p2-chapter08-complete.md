# 2부 8장 완료 — 자기 쓰기 알림

작성일: 2026-10-30

제공받은 PDF 38~39쪽을 기준으로 `announce_self_write`를 구현하고 Tauri invoke 처리기에 등록했다. async 커맨드로 현재 vault와 받은 root를 글자 그대로 비교하고 `wl://self-write` 이벤트를 보낸 창을 포함한 모든 창에 방송한다.

상대 경로 검사가 먼저다. 빈 경로, UTF-8 2,048바이트 초과, 맨 앞 `/`, `/`로 나눈 빈 마디·`.`·`..`를 거절한다. 현재 vault가 없거나 root가 다르면 유효한 요청을 조용히 null로 끝낸다. 경로의 실재 여부와 notes/ 소속은 검사하지 않으며 앞뒤 공백도 다듬지 않는다.

이벤트는 받은 `root`, 받은 `relPath`, 호출 창에서 얻은 `from` 세 문자열이다. 화면이 JSON에 from을 추가해도 호스트가 쓰는 창 이름표를 바꿀 수 없다. 모든 창에 같은 값을 보내고 수신 화면이 자신의 from을 거르는 방식이다. 2초 기록과 감시 알림 걸러내기는 3부 화면에서 연결한다.

Rust 테스트 44개와 설정 테스트 3개가 통과했다. Tauri MockRuntime의 실제 invoke 처리기를 통해 main·노트 창에서 호출하고 양쪽 Rust 이벤트 리스너가 같은 방송을 받는지 검사했다. 정확한 페이로드·실제 호출 창의 from·보낸 창 자신 수신·열기 전 무시·끝 빗금이 다른 vault 무시·잘못된 경로가 오래된 root 검사보다 먼저 거절되는 순서·존재하지 않는 경로·한글 UTF-8 바이트 경계를 확인했다. macOS `.app` 빌드도 확인했다.

실제 webview JS와 파일 감시의 2초 동작, 18장의 확인 페이지 전체 실행은 이번 범위에서 수행하지 않았다. 이전 장의 실제 Java 엔진 왕복 테스트는 함께 통과했다.

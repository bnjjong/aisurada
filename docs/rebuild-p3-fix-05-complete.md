# 3부 고치기 증분 5: 줄을 넘는 서식(C198)

[3부 고치기 플랜](rebuild-p3-fix-plan.md)의 증분 5에서 남은 C198을 넣었다. C197, C199, C200은 증분 4에서 짝짓기 함수와 함께 넣었다.

- 기준은 고치기 플랜의 「증분 5가 정한 C198의 경계」다. 기준 판은 aisurada `e454289`이다.

---

## 1. 고친 것

| 고치기 전 | 고친 뒤 |
|---|---|
| 편집기는 한 줄씩 들여와서, 인용(콜아웃 본문 포함), 목록 항목의 이어지는 줄, 하드 개행 문단에서 줄을 넘는 굵게를 짝으로 안 봤다. 다음 저장이 `\*\*`로 이스케이프해서, 다른 뷰어에서도 굵게가 사라졌다 | 한 블록 안에서 줄을 넘는 서식은 그 줄 끝에서 닫고 다음 줄 맨 앞에서 다시 연다. 편집기 들여오기와 읽기 화면이 같은 함수(`closeBlockEmphasis`, `editor/grammar.ts`)를 지난다 |

예: `> **굵게` 다음 `> 이어짐** 끝`은 `> **굵게**`, `> **이어짐** 끝`으로 저장된다.

### 경계(플랜대로)

| 무엇 | 넘나 |
|---|---|
| 이어지는 인용 줄, 콜아웃 본문 | 넘는다. 콜아웃 머리 줄은 블록에 안 든다 |
| 목록 항목과 들여쓴 이어지는 줄 | 넘는다 |
| 하드 개행(끝 공백 2개 이상, 끝 역슬래시)으로 이어진 문단 줄 | 넘는다. 닫는 표시는 하드 개행 표식 앞에 넣는다 |
| 안 들여쓴 이어지는 줄 | 안 넘는다. 편집기는 그 줄을 항목에 붙이는데 읽기 화면은 따로 그려서, 두 화면이 같은 블록으로 안 본다 |
| 빈 `>` 줄 | 안 넘는다(문단 경계) |
| 인용 안의 헤딩 꼴 줄, 목록 꼴 줄 | 블록을 끊는다 |
| 인라인 코드 | 줄을 안 넘는다. 짝짓기 함수의 코드 범위도 줄 안으로 묶었다 |
| 코드 펜스 안 | 손대지 않는다 |

아래 셋 가운데 하나에 걸리면 받은 줄을 그대로 둔다.

- 고친 줄을 줄마다 다시 짝지은 결과가 이은 글과 다르다. 글자마다 서식을 맞댄다.
- 넘는 짝의 표시가 링크 꼴 안에 있다.
- 블록이 1만 글자를 넘는다.

읽기 화면의 노트는 편집기처럼 줄 잇기를 먼저 해서, 맨 위 문단은 이미 한 줄이다. 바깥 md 파일은 줄을 잇지 않으므로, 줄바꿈으로 접은 맨 위 문단도 한 블록으로 보고 같은 함수를 지난다.

## 2. 시험

| 시험 | 무엇을 재나 |
|---|---|
| 왕복 사례 `C198a`(인용), `C198b`(목록 이어지는 줄), `C198c`(하드 개행), `C198d`(콜아웃 본문) | 줄마다 닫고 다시 연 글로 저장되고, 두 번 왕복해도 그대로다 |
| 왕복 사례 `C198e` | 안 들여쓴 이어지는 줄은 넘지 않는다. 지금 동작대로 `\*\*`로 저장된다 |
| `editor.test.mjs` 「C198: …」 | 빈 `>` 줄, 인용 안 헤딩과 목록, 안 들여쓴 줄, 닫는 표시 앞 공백, 코드 펜스, 1만 글자 초과는 그대로다. 취소선과 하이라이트, `***`, 역슬래시 하드 개행, 바깥 파일 문단 |
| `views.test.mjs` 「C198: …」 | 읽기 화면이 인용, 목록, 하드 개행, 바깥 파일 문단을 편집기처럼 줄마다 그리고, 빈 `>` 줄은 넘지 않는다 |

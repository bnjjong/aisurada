# 2부 14장 완료 — PTY

작성일: 2026-10-31

제공 PDF 60~63쪽대로 portable-pty 0.9.0의 실제 PTY와 /bin/zsh -l -i를 연결했다. TERM은 xterm-256color이고 HOME을 시작 위치로 쓰고, 없으면 호스트의 작업 폴더를 물려받는다. 키 문법은 제한하지 않는다. pty_start·write·resize·detach·alive·stats 여섯 커맨드를 등록했다.

입력은 전용 쓰기 스레드가 순서대로 write_all·flush한다. 출력은 8 KiB씩 읽어 base64 채널로 보내며, 2 MiB 재생 버퍼와 전체 출력의 바이트·덩이 수·FNV-1a 64비트 해시를 유지한다. 재접속은 버퍼를 먼저 보내고 기존 PTY 크기는 바꾸지 않는다. detach는 5분 유예를 두고 세대가 그대로인 인스턴스만 제거한다.

EOF 뒤에는 자식을 잠시 기다리고 필요하면 회수한다. main 페이지 로드의 시작·완료와 main 닫기 때 등록된 셸을 모두 회수한다. 부록 C51의 수정대로 오래된 읽기 스레드와 타이머가 같은 키의 새 인스턴스를 제거하지 못한다. 제거한 뒤 잠금 밖에서 종료한다.

Rust 검사에서 실제 PTY 입출력·재생·통계, 버퍼 상한과 해시, 재접속으로 무효화된 유예, 같은 키 교체 경합과 반복 회수를 확인했다. 실제 WKWebView에서 산술 echo 결과가 base64 채널로 오고 크기 변경·분리·재접속·exit·통계 점검이 통과했다. 셸 설정은 빈 임시 ZDOTDIR를 사용했다.

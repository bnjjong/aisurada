# 4부 다시 짓기 리뷰 반영

기준은 「withlog 4부 다시 짓기 리뷰 — 이름은 맞췄지만 4부 엔진이 꺼져 있고 claude에 닿는 부름이 안 이어진다」(2026-11-04, aisurada `64b5c3f`)다. 줄 번호(H, M, L)는 그 리뷰의 번호를 그대로 쓴다. 설명서 원문은 `withlog-4부-Claude-연동-설명서.pdf`(226쪽)이고, 리뷰가 「오늘 고친 자리」로 적은 줄은 리뷰 글의 예와 기대값을 따랐다. 그 PDF 본문이 아직 옛 글인 자리는 2절에 적었다.

- 다르게 지은 107줄 가운데 엔진 23줄과 호스트 13줄은 모두 고쳤다. 묻기 화면 31줄과 세션 화면 40줄은 아래 표의 「못 한 것」을 뺀 줄을 고쳤다.
- 기록과 코드가 다른 31곳은 코드를 맞추면서 기록을 바로잡았다. 기록이 코드와 달라서가 아니라 코드가 틀려서 생긴 줄은 코드를 고쳤더니 기록이 맞게 됐다.
- 설명서 쪽 빈틈 12곳은 설명서를 고치는 일이라 이 저장소에서는 안 했다.

검증은 `bash test.sh`(엔진 Java 시험 전체), `bash test-native.sh`(화면 시험, 호스트 cargo 시험 88건, 화면 빌드 두 가지)로 했다. 실제 앱 창으로 보는 받아들임(`test:*:acceptance`)은 이 환경에서 돌리지 못했다.

# 2부 15장 완료 — 비밀 가림

작성일: 2026-10-31

제공 PDF 64~70쪽의 probe·status·mask·shapes 네 커맨드를 구현했다. 값 보관 타입에는 Debug와 Serialize를 구현하지 않고, 응답은 준비 여부·개수·이름·가린 글만 반환한다. probe는 실제 커맨드가 호출될 때만 .zshrc의 관리 블록, 빌드에 포함한 분류표, 로그인 셸의 NUL 구분 환경을 읽는다. stdout·stderr를 오류나 로그에 넣지 않는다.

30초 제한은 기존 계약대로 기다리기만 멈추고, 일꾼이 자식을 끝까지 회수한다. 표 뜨기에 실패하면 이전 표도 사용할 수 없게 바꾸고, 성공하면 이전 값과 합집합을 만든다. 상태 개수는 새 회차의 값이다. 표가 없으면 가리기를 거절한다. 값은 유니코드 문자 수가 긴 차례로 치환하며 여러 줄 값도 가린다.

모양 검사는 PEM·16개 접두어·JWT·URL 자격증명을 바이트로 세고, 위치나 부분 문자열을 반환하지 않는다. 가린 표식의 URL은 다시 세지 않는다. 결과 순서와 사람용 label도 호스트에서 정한다.

지어낸 값으로 관리 블록·분류·NUL·읽을 수 없는 값·짧은 값·회전 합집합·실패 폐쇄·가림 순서와 응답의 값 누출 부재를 검사했다. 16개 접두어 각각의 길이 문턱, 낱말 경계, URL·PEM·JWT 경계도 검사했다. 실제 WKWebView에서 빈 표 가림 거절과 모양 개수 점검이 통과했다.

사용자의 실제 .zshrc·Keychain은 읽지 않았다. 실 비밀 이름 표는 Git에 넣지 않는다. 이 빌드는 항목 없는 견본을 포함하므로 실제 probe 성공과 굳히기의 사용자 확인은 실 분류표를 넣은 빌드에서 수행해야 한다.

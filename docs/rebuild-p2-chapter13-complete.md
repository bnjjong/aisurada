# 2부 13장 완료 — 모니터와 데스크톱

작성일: 2026-10-31

제공 PDF 56~59쪽대로 모니터 이름과 반올림한 논리 크기로 환경 이름표를 만들고, 환경별 main·note:<id>·note:last 칸을 window-layouts.dev.json에 저장한다. 모니터 상대 dx·dy를 사용하며 복원 때 모니터와 점이 유효한지 다시 본다.

옮김·크기·포커스 이벤트의 마지막 예약만 400밀리초 뒤 기록한다. 전체 화면·최소화는 제외한다. 같은 모니터에서 데스크톱 질의가 실패하면 기존 번호를 보존하고 note:last에는 번호를 싣지 않는다. 레이아웃 값이 바뀔 때만 파일을 쓰고 main의 마지막 자리 파일은 매번 쓴다.

창 번호는 main 스레드에서 AppKit에 묻는다. yabai는 고정 절대 경로 두 곳만 찾고 USER 대체 값, 질의별 2초 제한, 모니터 사각형 1픽셀 판정, 생성 직후 질의 재시도와 데스크톱 이동을 구현했다. 없거나 실패해도 창 생성은 성공한다.

Rust 검사에서 위치 맞추기·환경별 조회·같은 모니터의 번호 보존·note:last 번호 제외·원자적 JSON과 손상 파일을 확인했다. 실제 WKWebView 회차 뒤 레이아웃 파일 모양 점검도 통과했다. 모니터 조합 변경과 yabai가 실제 데스크톱을 옮기는 동작은 자동 검증하지 않았다.

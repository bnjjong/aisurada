# 2부 6장 완료 — 자식 프로세스와 환경

작성일: 2026-10-30

제공받은 PDF 32~34쪽을 기준으로 환경 정리를 보완하고 공통 프로세스 실행기를 추가했다. 호스트 기동 첫 걸음에서 Claude·cmux 표식이 있을 때만 문서의 이름과 접두어를 지운다. 사용자 Claude 설정, 터미널 설정과 UTF-8이 아닌 환경 이름·값은 보존한다. cmux의 NODE_OPTIONS는 주입 표식이 있는 경우에만 원래 값으로 되돌리거나 지운다. `vars_os`를 사용해 UTF-8이 아닌 값 때문에 호스트가 기동하지 못하는 문제를 없앴다.

프로세스 실행기는 입력이 있으면 별도 스레드가 파이프에 쓰고 닫으며, 없으면 stdin을 `/dev/null`로 연결한다. stdout과 stderr는 각각 다른 스레드에서 EOF까지 읽는다. 두 출력과 자식 종료가 확인되면 결과를 반환한다. 시간 초과에는 `/bin/kill -TERM <pid>`를 보내고 최대 3초 동안 50ms 간격으로 확인하며, 남아 있으면 SIGKILL하고 wait로 회수한다. 직접 띄운 자식 하나만 대상으로 한다.

유휴 파이프와 자식 종료의 차이를 유지했다. 자식이 끝났어도 손자가 출력 파이프를 쥐고 있으면 EOF가 오지 않아 상한으로 끝난다. 시간 초과 결과를 반환할 때 손자가 잡고 있는 출력 읽기 스레드는 그 파이프가 닫힐 때까지 남을 수 있다. 자식이 stdout/stderr를 먼저 닫고 계속 실행하는 경우에도 시간 제한은 작동한다.

실제 프로세스로 200KB stdin/stdout과 독립적인 200KB stderr, EOF 입력, 비정상 종료, TERM 정리, TERM을 무시하는 자식의 KILL 회수, 출력이 닫힌 자식, 손자가 출력 파이프를 잡는 경우와 그 손자의 생존을 검증했다. 짧은 내부 상한과 유예를 써서 검증하며 제품 상한은 wl-cli 120초·종료 유예 3초다. 전체 Rust 테스트 34개와 설정 테스트 3개가 통과했다.

로그인 셸과 yabai는 각각 14~15장과 13장에서 연결한다. 비밀 표 로그인 셸의 30초 뒤 기다리기만 멈추는 규칙은 이 종료 실행기를 적용하지 않는다. 현재 제품 호출자는 sidecar_call이며, 후속 yabai 호출에서도 같은 실행기를 사용할 수 있다. macOS `.app` 빌드도 통과했다.

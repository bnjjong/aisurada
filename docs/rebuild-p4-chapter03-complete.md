# 4부 3장 묻기 한 번 구현 기록

2026-11-04 2차 반영본 확인에 맞춰 낡은 모델 목록, 물음 글 예, 저장 대상과 검증 설명을 정정했다.

## 구현

- 모델은 `claude-opus-5-5`, `claude-opus-5`, `claude-sonnet-5-5`, `claude-sonnet-5`, `claude-fable-5-1`, `claude-fable-5`이고 기본은 `claude-sonnet-5-5`다. effort는 `low`, `medium`, `high`, `xhigh`, `max`이고 기본은 `low`다.
- 페르소나는 `askPersona`의 3줄을 별도 `persona` 인자로 보낸다. 첫 `#` 제목은 공백 또는 탭 뒤를 읽고 HTML 주석을 뺀 결과가 비면 제목 없음으로 끝낸다.
- 첫 물음 본문은 작성 세션 묶음(있을 때), 저장소 줄(있을 때), 노트 id와 읽기 명령 줄, 빈 줄, `[대목] 「…」`, 빈 줄, 안내 문장, 빈 줄, 질문 차례다. HTML과 그림 안내는 그 뒤에 온다. 끝 개행은 없다.
- 이어 묻기는 편 대목과 빈 줄, 질문을 쓴다. 대목의 탭은 ` | `, 나머지 연속 공백은 빈칸 하나로 바꾼다.
- 작성 세션 묶음은 `authorParts`가 24,000자 예산으로 한 창 또는 두 창을 고른다. `creation`이 빠지면 `latest`에서 처음 언급까지의 회차를 쓴다. 제목 뒤, 전사 앞, `## 물음` 앞뒤에 빈 줄이 있다. 이름 없는 도구 회차는 줄을 만들지 않는다.
- 그림은 붙이는 순간 MIME, 5,000,000바이트, 8장 상한을 검사한다. 단일 파일 노트는 그림을 둘 폴더가 없다는 안내를 보인다. 쓰기는 IPC 본문과 `x-wl-note-dir`, `x-wl-name` 헤더를 쓴다.
- D4는 성공한 답이 없을 때 다음 실제 물음에도 작성 세션 묶음을 싣는 규칙이다. 그림 때문에 실제로 묻지 못한 회차에는 `sessionLines`를 안 남긴다.
- 대목은 저장할 때 앞뒤 공백과 표 줄의 끝 개행을 보존하며 길이만 제한한다. 물음과 답도 UTF-16 상한과 서로게이트 경계 규칙으로 자른다.
- 같은 노트의 물음은 FIFO로 서고 출발할 때 스토어를 다시 읽는다. 저장 실패 답은 메모리에 남긴다.
- 저장 키는 이름 변경 후 `aisurada.ask.v1`이다. 디스크에 남기는 값은 `pending`, `abandoned`, `model`, `effort`이고 `unseen`, 실타래 캐시, 런타임은 창 메모리다. 노트 창은 `aisurada.ask.note-<id>.v1`을 쓴다.

- 24.3과 24.4: 도구와 명령 표면의 문법 오류 문구, 갈래와 유형의 다듬기와 소문자, 전각 글자 거절, `bodies`의 대소문자, 갈래가 `bodies`보다 먼저, `get_template`의 `{}`와 빈 id, 끝 LF가 붙은 id, `WL-404`, 도구 `body`의 200,000자 경계, 만들기의 본문·이름·유형 차례, 공백뿐인 id의 고치기, 리추얼 id를 고치면 `WL-404`, `format`과 `rev` 칸 거절, 표식이 값 검사보다 먼저, 읽기는 표식을 안 봄

## 2. 목록에서 빠진 것을 짚은 것

- 26번은 목록의 읽기와 설명서가 다르다(위 표). 설명서를 따랐다.
- 8번은 설명서 14.10이 글자를 코드 상자와 표 칸의 코드 글로 적어서 띄어쓰기가 그대로 계약이다. 14.9는 같은 글을 조금 달리 인용한다(`tableSize종`). 본문(14.10)을 기준으로 삼았고, 창 안 문구(14.9)는 그 문구대로 뒀다.
- 터미널 받아들임(`navigation`)에 점검을 하나 더했다. xterm이 실제 창에 뜨고, 셸이 떠서 「굳히기」가 켜지고, `pty_write`로 보낸 명령의 출력이 논리 줄 수로 잡히는 것까지 잰다.
- 설명서 12.4는 일 보기 시작 시각의 아래 끝을 00:00, 위 끝을 23:00 − 소요 시간으로 적는다. 증분 2에서 이 범위를 그대로 뒀었는데, 이번에 5번으로 고쳤다.

- 28번을 고치자 interaction 받아들임의 하위 노트 사슬 점검이 실패했다. 원문 4.8은 링크로 하위 페이지를 열 때 「도착할 주소는 /doc/<맨 위 노트 id>」를 **항상** 적는다고 하는데, 다시 지은 화면은 이미 그 주소에 있으면 `null`로 적어 왔다. 같은 주소로 가는 이동을 안 세던 때는 그게 드러나지 않았다. 링크 길만 항상 적게 고쳤다(`openSubNotes`의 `alwaysArrive`).

## 4. 그대로 둔 것

- 3번(4부 꽂이 6자리)은 다음 묶음이다. 빈 구현으로는 시험할 수 없고, 17.5~17.6의 연동 규칙(`RailProjects` 자리, 세션 칩, 셸 판정의 세션 답)을 따로 읽어 지어야 한다.
- 터미널의 글꼴은 파일의 두 조건(한글 너비, 상자 글자)까지만 쟀다. 한글과 상자 글자를 실제로 찍어 눈으로 보는 일은 설명서가 손 확인으로 남겨 둔 것이라 안 했다.
- 한글 조합 중 Enter, 붙여넣기의 WebKit 허락 메뉴, `[?2004h`가 보이는지는 목록이 「손으로 봐야 안다」고 뺀 것이라 그대로다. 1번으로 터미널 라이브러리가 들어왔으니 18.10 손 확인에서 본다.
- 템플릿 저장이 쓰기 줄을 서지 않는 것(겹친 저장), 설명서 쪽 고칠 곳은 이 목록 밖이다.

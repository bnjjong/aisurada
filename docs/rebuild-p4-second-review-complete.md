## 기록 정정

3장 기록의 모델/effort 목록, 물음 글과 묶음 예, 저장값을 다시 적었다. 5장 런타임과 프로세스 회수, 6장 공통 프로세스 함수와 테스트 수, 9장 상한과 D29, 10장 받아쓰기/셸 명령/cwd 출처를 정정했다. 이전 반영 기록의 잘못된 완료 주장, L4, 빈 줄, 처음 제목, 레일 유지 설명도 바로잡았다. 과거 실행 수는 과거 기록임을 표시했다.

D35(도구 줄 다음 회차의 빈 줄)와 D36(살아 있는 세션이 목록에 나타나 입력창이 닫히는 동작)은 리뷰가 현재 설명서와 같다고 판정한 미결정 후보이므로 이번 결함 수정에 포함하지 않았다. 선택 기능인 wl-agent doctor 확장과 원본 설명서 자체의 편집은 범위 밖이다.

- `bash test.sh`: 전체 Java 검사 통과. 이번 엔진 리뷰 회귀는 136개 검사다. noclaude 명령과 serve 왕복도 실제 별도 jar로 검증한다.
- `bash test-native.sh`: 성공. Node 검사 429건 통과, Rust 88건 통과(별도 통합 검사가 호출하는 probe 1건은 단독 실행 제외), 기본 화면 빌드와 타입 검사 성공.

- `pnpm --dir native-host test:ask-marks:acceptance`: 실제 4부 없는 화면과 Rust 호스트에서 5/5 통과. `ask_runtime` 미등록, 표식 보존, AI 점 0개, 노트/하위 노트 열기를 확인했다. Tauri CLI가 기본 기능을 다시 더하는 것을 피하려고 이 검사는 같은 설정을 전달한 `cargo run --no-default-features`를 사용한다.
- Vite 개발 서버 `/scripts/part4-review.html`: ego-browser에서 7/7 통과. 실제 React 마운트/언마운트, 안정된 스냅샷, 입력·그림·도는 요청·못 적은 답의 복구, 중복 보내기 차단, 카드 고정과 크기 상한 저장, 고리 칠하기 정지, 목록 대기, 굳히기 재시도, CLI 칸 유지와 접을 때 detach 없음 검사다.
- 기본 앱의 샘플 노트를 브라우저에서 열어 렌더링을 시각 확인했다. `git diff --check` 통과.

호스트 받아들임은 로컬 가짜 Claude 실행 파일을 쓰며, 브라우저 상태 검사는 모의 IPC를 사용한다. 사용자 계정으로 실제 Claude 모델에 물음을 보내거나 배포하지 않았다.
